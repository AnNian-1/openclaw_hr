### 问题 1：并发子 Agent 上限为 5 ⚠️ 中

| 项目 | 内容 |
|------|------|
| **严重程度** | ⚠️ 中 |
| **发现场景** | 第一轮测试中，测试 7（跨领域请求）在前 5 个业务测试尚未完成时发起，被系统拒绝 |
| **错误信息** | `sessions_spawn has reached max active children for this session (5/5)` |
| **影响** | Router 同一时刻最多调度 5 个子 Agent。若 5 个领域同时有任务在跑，新请求必须排队等待。高峰期（如月初批量入职 + 绩效评估季）可能出现响应延迟 |
| **当前规避方式** | 等待前序任务完成后再发起新请求（分 3 批次完成全量测试） |
| **建议** | 评估是否需要提升并发上限，或在 Router 层增加排队/优先级机制，对高优请求（如员工紧急咨询）优先调度 |
| **2026-08-30 修复** | 已把 defaults 上 `maxChildrenPerAgent` 调到 8。不可写在 `agents.list[].subagents`（2026.5.12 会拒启动）。满员时 SOUL/AGENTS 规定告知用户等待。 |
| **回测验证** | ✅ 第一批成功 spawn 8 个子 Agent，无需分批 |
