## 岗位职责

1. 负责电商推荐 / 搜索链路的召回、粗排、精排模型迭代，支撑日均 12 亿次推荐请求。
2. 参与特征工程、样本构建、在线推理服务优化，对 CTR/CVR 与延迟（P99 < 50ms）负责。
3. 跟进大模型 / 多模态在推荐场景的落地实验，沉淀可复用的实验框架。
4. 与产品、数据、工程协作，推动算法效果与业务指标对齐。
5. 参与 Code Review 与技术方案评审，维护模型与特征文档。

## 任职要求

**硬性要求**
- 硕士及以上学历优先，计算机 / 数学 / 统计相关专业，985/211 优先。
- 3-6 年推荐 / 搜索 / 广告算法经验，熟悉深度学习框架（PyTorch / TensorFlow）。
- 扎实的机器学习与概率统计基础，能独立完成离线评估与在线 A/B。
- 熟悉常见召回（双塔、ANN）与排序（DeepFM、DIN 等）结构。
- 具备 Python / C++ / Go 至少一门工程能力，能与在线服务联调。

**加分项**
- 有亿级用户规模推荐系统实战经验。
- 顶会论文或开源贡献。
- 熟悉特征存储、实时样本流、模型平台。

**软素质**
- 数据驱动，能把业务问题拆成可验证假设。
- 跨团队沟通顺畅，结果导向。
