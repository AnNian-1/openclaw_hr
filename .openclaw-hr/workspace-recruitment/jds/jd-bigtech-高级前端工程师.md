## 岗位职责

1. 负责电商 C 端核心链路（商详、下单、会员）的前端架构与交付，支撑大促峰值。
2. 主导 React + TypeScript 组件库与微前端治理，对 Core Web Vitals 与可访问性负责。
3. 与设计、后端、数据协作，推动灰度发布、监控与前端稳定性建设。
4. 参与 Code Review、技术方案评审，带教中级前端。

## 任职要求

**硬性要求**
- 本科及以上，计算机相关专业；5 年以上前端经验，其中 3 年以上 React。
- 精通 TypeScript、React 18、状态管理（Redux / Zustand）、工程化（Vite / Webpack）。
- 熟悉性能优化、SSR/CSR、微前端（qiankun 或 Module Federation）。
- 有大型互联网 C 端或中后台复杂系统经验。

**加分项**
- 有设计系统 / 组件库从 0 到 1 经验。
- 熟悉 Node.js BFF、GraphQL、可视化（ECharts）。
- 有 WASM、WebGL 或跨端（RN / Taro）经验。

**软素质**
- 结果导向，能在大促窗口独立扛需求；沟通清楚，能推动跨团队事项。
