## 岗位职责

1. 负责核心业务 API 与数据服务开发（Python / Go），支撑日活约 80 万用户。
2. 参与从 0 到 1 的模块设计，快速迭代 MVP。
3. 维护云上基础设施（容器、CI/CD、监控），保障可用性 ≥ 99.9%。
4. 与产品、前端紧密协作，周发版节奏。
5. 参与 Code Review，推动工程规范落地。

## 任职要求

**硬性要求**
- 本科及以上，2-5 年后端经验。
- 熟练 Python 或 Go，熟悉 PostgreSQL / Redis / Kafka 至少两种。
- 能独立负责模块，有线上排障经验。
- 接受创业不确定性，能扛短期高强度。

**加分项**
- 有早期团队或从 0 搭建服务经验。
- 熟悉 主流公有云（比赛表述，不特指厂商）。
- 全栈能力（会一点前端）加分。

**软素质**
- Owner 意识强，沟通直接，执行快。
