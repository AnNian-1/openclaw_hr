## 岗位职责

1. 负责 App 拉新、激活、留存相关产品设计，目标季度新增 UV 提升 15%。
2. 设计并推动增长实验（落地页、激励、推送策略），周均实验 ≥ 8 个。
3. 协同算法、运营、设计落地功能，对核心漏斗转化率负责。
4. 输出 PRD、原型与数据复盘，沉淀增长方法论。
5. 关注竞品与行业动态，提出可落地的产品机会。

## 任职要求

**硬性要求**
- 本科及以上，3-5 年 C 端产品经验，有增长 / 社区 / 电商经验优先。
- 能独立完成需求分析、方案设计、项目推进与数据复盘。
- 熟悉常用数据分析方法，能读懂漏斗与归因。
- 具备良好的文档与跨团队推动能力。

**加分项**
- 有从 0 到 1 或从 1 到 100 的增长案例。
- 懂基础 SQL / 埋点方案。
- 有 B 端或中台协作经验。

**软素质**
- 用户同理心强，抗压，能在不确定中快速试错。
