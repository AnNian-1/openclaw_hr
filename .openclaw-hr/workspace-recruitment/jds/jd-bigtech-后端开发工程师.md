## 岗位职责

1. 负责电商交易链路核心系统（订单、履约、库存）的服务端设计与开发，支撑大促峰值场景（去年双十一订单峰值 58 万笔/秒）。
2. 主导或参与交易中台微服务的拆分、治理与稳定性建设，对所负责模块的 SLA（可用性 99.99%）、RT（P99 < 200ms）负责。
3. 参与核心链路的容量评估、限流降级、全链路压测，配合大促保障值班。
4. 持续优化系统性能与成本，识别并解决慢 SQL、热点 Key、缓存击穿等线上问题。
5. 参与技术方案评审、Code Review，沉淀技术文档，对团队代码质量与技术规范负责。
6. 跟进新技术调研与落地（如 Service Mesh、云原生改造），推动工程效率提升。

## 任职要求

**硬性要求**
- 本科及以上学历，计算机、软件工程相关专业，985/211 优先。
- 3-6 年服务端开发经验，主语言 Java 或 Go，有大型互联网公司经验者优先。
- 扎实的计算机基础：数据结构与算法、操作系统、网络、数据库原理。
- 精通 Spring / Spring Boot / Spring Cloud 或 Go 微服务框架；熟悉 MySQL、Redis、Kafka / RocketMQ。
- 有高并发、高可用、分布式系统实战经验，理解 CAP、分布式事务、最终一致性。
- 有线上系统问题排查与性能调优的实战经历。

**加分项**
- 有交易、支付、履约等核心电商链路经验。
- 参与过日订单千万级以上系统的架构设计或重构。
- 熟悉 K8s、Service Mesh、可观测性体系（Metrics / Tracing / Logging）。
- 有技术社区影响力（开源贡献、技术博客、专利）。
- 有 ACM / 蓝桥杯等竞赛获奖经历。

**软素质**
- 结果导向，能在高压与快节奏下交付；Owner 意识强，对结果负责到底。
- 良好的抽象与系统设计能力，复杂问题拆解能力强。
- 主动沟通，能跨团队协作推动事情落地。
