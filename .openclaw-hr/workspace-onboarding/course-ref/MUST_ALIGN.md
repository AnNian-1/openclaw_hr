# 入职 · 现行必须对齐（更新 INTRO 时不得写成课程旧状）

- HCM 是独立应用，不是 Agent。入职小慧只 **GET** 花名册/节点，不向 HCM 写入、不悄悄建人。
- 合同内容、账号权限两道门必须人批准；不能代批。halt ≥ 3 天只催办，不自动 resume。
- 五部门节点都 `completed` 后，才挂试用期 7/30/60/90。
- `pending-approvals/` 已落地（课程里曾写「token 易丢、待做」）。`approvalId` 不能顶替 `resumeToken`。
- 无拼音处理重名。不要把「未开始」写成「已完成」。
- 子 Agent 不能互相 spawn。
