# 360 综合分析报告模板

看板脚本 `parse_aggregated_report()` **只认**下面结构。自由发挥的 Markdown 会报「缺少可展示的语义摘要」。

## 总览

| 维度 | 判定 |
|------|------|
| 目标达成 | 共识 |
| 专业能力 | 共识 |
| 协作沟通 | 分歧 |
| 责任心 | 共识 |
| 学习成长 | 共识 |

判定列必须出现「共识」或「分歧」字样（可用「边界共识」）。

## 分维度

每个维度一节，标题匹配：`### N. 维度名 —— 简述`

共识维度正文必须有加粗标签 **判定：** 后跟至少约 8 字说明。  
分歧维度优先 **分歧归因分析：**（或 **归因分析：**）。

### 1. 目标达成 —— 各视角叙事一致

**判定：** 上级、平级、下属与自评均认为本周期目标按计划推进，核心叙事一致。

### 2. 专业能力 —— 交付质量稳定

**判定：** 各视角均认可专业产出达到岗位要求，未出现系统性能力质疑。

### 3. 协作沟通 —— 信息同步节奏不一致

**分歧归因分析：** 上级强调跨组同步偏慢，平级则认为接口对齐已经足够；需要在例会上统一「同步完成」的定义。

### 4. 责任心 —— 收口意识明确

**判定：** 各视角均提到对结果负责，超时项能主动升级，未形成对立叙事。

### 5. 学习成长 —— 方法沉淀可见

**判定：** 自评与他评都提到本周期有可复用的方法沉淀，成长方向一致。
