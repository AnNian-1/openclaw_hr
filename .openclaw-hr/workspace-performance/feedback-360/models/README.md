# 360° 绩效反馈表模板（2026年版）

正式 HR 文书版——通用可填写反馈表。

## 文件

| 文件 | 说明 |
|---|---|
| `360-feedback-form-blank.docx` | 通用模板；评估人代号填 领导1 / 同事1 / 下属1 / 自评 |
| `build_templates.py` | 再生脚本 |

## 字体层级

| 用途 | 字体 |
|---|---|
| 大标题 | 黑体 |
| 章节标题 | 黑体 |
| 正文 / 说明 | 宋体 |
| 表单标签 / 下拉 | 微软雅黑 |

## 单选

关系、评分使用下拉列表：单击「请选择（单选）」→ 下拉选一项。

## 再生

```bash
cd feedback-360/models
python3 build_templates.py
```
