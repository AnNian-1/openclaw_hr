## 二、OpenClaw 会话怎样接到云上

### 2.1 落盘位置（本机约 290MB 会话 + 约 42MB sqlite）

```
.openclaw-hr/agents/<agentId>/sessions/   # jsonl 正文 + sessions.json 索引
.openclaw-hr/memory/*.sqlite              # memorySearch（按 agent 分库）
.openclaw-hr/workspace-*/memory/*.md      # session-memory 钩子写下的日记
.openclaw-hr/hcm/hcm.db                   # 入职花名册 SQLite（gitignore）
.openclaw-hr/cron/jobs.json               # Cron 定义（已入库，但路径是本机绝对路径）
```

Agent 目录：`er-admin`、`er-admin-cron`、`main`、`onboarding`、`performance`、`recruitment`、`router`、`training`。  
`session.dmScope` = `per-channel-peer`：同一飞书用户继续私聊，会命中 `sessions.json` 里 `origin.from` = `feishu:ou_…` 的那条，**续上旧 jsonl**，而不是新开空白会话。

`sessions.json` 里的 `sessionFile` 是**绝对路径**，例如：

`/home/yhwz/openclaw-hr/.openclaw-hr/agents/er-admin/sessions/<uuid>.jsonl`

换目录后若不改写，Gateway 会认为会话文件不存在，等于失忆。

### 2.2 建议：rsync 运行时（不要 git 推会话）

在本机打包或直传（示例，按实际云主机用户改）：

```bash
# 在本机执行。不要带 node_modules、env.sh 以外的密钥副本到不可信盘。
rsync -aH --info=progress2 \
  --exclude 'node_modules/' \
  --exclude '.openclaw-hr/install/' \
  --exclude '.openclaw-hr/npm/' \
  --exclude '.openclaw-hr/nginx/logs/' \
  --exclude '.openclaw-hr/nginx/temp_*' \
  --exclude '_ref/' \
  --exclude 'hr_claw_hub.tar.gz' \
  /home/yhwz/openclaw-hr/  user@cloud:/opt/openclaw-hr/
```

若 GitHub 已是代码源，云上 `git clone` 后再 **只补拷** gitignore 的运行时：

```
.openclaw-hr/env.sh                          # 密钥，走 scp，不要进 git
.openclaw-hr/agents/*/sessions/
.openclaw-hr/memory/
.openclaw-hr/workspace-*/memory/
.openclaw-hr/hcm/hcm.db
.openclaw-hr/exec-approvals.json             # 已 tracked 但本地常脏；云上以本机这份为准
```

然后在云上把所有 `/home/yhwz/openclaw-hr` 改成新根路径。`setup.sh` **只会**改写 `/Users/hsail/.openclaw-hr` 和 `/root/.openclaw-hr`，**不会**改当前 WSL 路径，迁云时必须自己 sed 或改 `setup.sh`。

`cron/jobs.json` 的 `payload.message` 里也有本机绝对路径（入职 review、月末月报），不改则 Cron 在云上会跑到不存在的脚本。

### 2.3 接上的前提与接不上的情况

**能续上飞书上下文，需要同时满足：**

- 同一飞书企业应用（`appId` 仍是 yaml 里那个 SecretRef 指向的应用）。
- 用户 `ou_*` 没变。
- Agent id 没改（尤其飞书绑定的是 `er-admin`，不是 `router`）。
- `sessions.json` + 对应 jsonl 在，且路径已改写。

**仍会对不齐：**

- 换了一套飞书应用 / 新租户 → open_id 全变，旧会话作废。
- 只 clone GitHub、不拷 sessions → 飞书用户看起来像第一次说话。
- Cursor 聊天：即使拷了 `~/.cursor/projects/.../agent-transcripts/`，新工程路径通常也对不上，**不要指望**。

### 2.4 不要用 OpenClaw Dreaming 当备份

`hooks.internal.session-memory` 是开的（会写日记 md）。**Dreaming 保持关闭**，未做记忆清洗前不要开 Deep。日记里已有冒烟过程与七月回忆，promote 阈值相关，乱开会把测试垃圾写进长期记忆。
