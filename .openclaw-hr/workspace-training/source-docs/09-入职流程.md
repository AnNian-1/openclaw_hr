# 某某公司 · 入职流程

> 适用范围：新入职员工 / 招聘 HR / 用人部门
> 法规依据：《劳动合同法》《就业服务与就业管理规定》
> 最近更新：2026-05

## 一、入职流程总览

```
Offer 接受 → 背景调查 → 入职准备 → 报到当天 → 入职后跟进
   ↓             ↓           ↓          ↓           ↓
确认接受     材料核验    工位/设备    签合同/办手续  导师带教
```

## 二、入职前准备（候选人接受 Offer 后）

### 2.1 入职材料清单

候选人需在报到当天提交以下材料（原件核验、复印件存档），HR 在发 Offer 时一并告知：

| 材料 | 说明 |
|---|---|
| 身份证 | 原件核验，复印件存档 |
| 学历学位证书 | 原件核验；公司通过学信网核验真实性 |
| 离职证明 | 原单位出具的解除/终止劳动关系证明 |
| 银行卡 | 公司代发工资合作银行的储蓄卡 |
| 一寸照片 | 用于工牌、人事档案 |
| 体检报告 | 入职体检合格报告（公司指定或认可的体检机构）|
| 个人信息登记表 | 入职信息采集（详见《12》合规说明）|
| 专业资格证书 | 岗位要求的执业/职业资格证书（如有）|

> 合规提示：公司**不得**要求劳动者提供担保或以其他名义向劳动者收取财物（《劳动合同法》第九条）；**不得**扣押劳动者的身份证、学历证书等证件原件。

### 2.2 背景调查

- 公司对部分岗位（管理岗、涉密岗、关键岗）开展背景调查；
- 背景调查须在**取得候选人书面授权**后进行，调查范围限于与履职相关的信息（学历、工作经历、任职情况），不得调查与岗位无关的个人隐私；
- 背景调查结果仅用于录用决策，按个人信息保护要求处理（详见《12》）。

### 2.3 入职准备（HR + IT + 行政协同）

HR 在候选人报到前完成：

- 分配工号、企业邮箱、企业微信账号；
- 通知 IT 准备办公电脑及账号权限；
- 通知行政准备工位、门禁卡、办公用品；
- 安排导师（Mentor）；
- 准备劳动合同及入职文件。

## 三、报到当天

### 3.1 手续办理（HR）

1. **核验入职材料**，收取复印件存档；
2. **签订书面劳动合同**——某某公司要求入职当天即签订，明确合同期限、试用期、岗位、薪资、工作地点等（详见《01》）；
3. 签署《岗位说明书》《保密协议》《员工手册确认书》《试用期录用条件确认书》；
4. 签署《个人信息处理告知与同意书》（详见《12》）；
5. 办理社保公积金增员（自用工之日起参保，详见《04》）；
6. 采集银行卡信息，建立薪酬发放档案。

### 3.2 IT 与办公（IT + 行政）

- 领取办公电脑，开通系统账号与权限；
- 领取门禁卡、工牌；
- 熟悉工位与办公环境。

### 3.3 入职培训

- 完成公司级 Onboarding 第一课（公司介绍、文化、核心制度、安全合规、IT 与 HR 系统使用）；
- HR 数字员工「小慧」会主动向新员工推送入职指引，新员工可随时向小慧咨询。

## 四、入职后跟进

| 时间节点 | 跟进事项 |
|---|---|
| 入职第 1 周 | 完成公司级 Onboarding；导师启动带教；融入团队 |
| 入职第 1 个月 | 部门岗位培训；HR 进行第一次新人关怀沟通 |
| 入职第 3 个月 | 导师带教结束；6 个月试用期者进行中期反馈 |
| 试用期满前 2 周 | 直接主管发起转正考核（详见《01》《05》）|
| 转正 | 办理转正手续，更新人事档案，享受转正后福利（详见《07》）|

## 五、内部推荐入职（内推）

- 公司鼓励员工内推优秀人才；
- 内推候选人入职并**通过试用期**后，推荐人可获得内推奖金（标准按岗位级别在内推制度中规定）；
- 内推流程与正常招聘一致，候选人须通过正常面试评估，内推不降低录用标准。

## 六、试用期转正

- 试用期满前两周由直接主管发起转正考核，依据《试用期录用条件确认书》进行；
- 考核通过：HR 办理转正，确认转正薪资（某某公司试用期已按 100% 发薪，转正一般不变），更新档案；
- 考核未通过：按《01》试用期解除规定处理，须有客观依据。

## 七、常见问题

**Q：入职要带哪些材料？**
A：身份证、学历学位证、离职证明、银行卡、一寸照、入职体检报告，岗位有要求的还需职业资格证书。HR 发 Offer 时会给完整清单。

**Q：公司会扣我的身份证或学历证原件吗？**
A：不会。法律明确禁止用人单位扣押员工证件原件。公司只核验原件、留存复印件。

**Q：入职要交押金或保证金吗？**
A：不需要，也绝不允许。法律禁止用人单位以任何名义向劳动者收取财物或要求提供担保。

**Q：劳动合同什么时候签？**
A：某某公司要求报到当天即签订书面劳动合同，不会拖延。

**Q：内推朋友进公司有奖励吗？**
A：有。内推候选人入职并通过试用期后，推荐人可获得内推奖金，标准按岗位级别确定。内推不降低录用标准。

**Q：没有离职证明能入职吗？**
A：原则上需要原单位的离职证明以确认劳动关系已解除。确有困难的，请尽早与 HR 沟通，避免双重劳动关系风险。
