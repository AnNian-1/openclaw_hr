# 某某公司 · 培训与晋升通道

> 适用范围：全体员工
> 最近更新：2026-05

## 一、培训体系

公司培训分为四类，覆盖员工从入职到成长的全周期：

| 培训类型 | 对象 | 内容 |
|---|---|---|
| 入职培训（Onboarding）| 新员工 | 公司文化、制度、业务概览、岗位融入 |
| 通用能力培训 | 全员 | 沟通协作、项目管理、职场效能等软技能 |
| 专业/技术培训 | 各专业线 | 岗位专业技能、技术栈、行业知识 |
| 管理者培训 | 主管及以上 | 团队管理、绩效辅导、招聘面试技能 |

### 1.1 新员工入职培训

- 新员工入职首周完成公司级 Onboarding（文化、制度、安全合规、IT 使用）；
- 入职首月由部门安排岗位融入培训与导师带教（详见《09-入职流程》「导师制」）；
- 入职 90 天内完成岗位胜任所需的核心培训。

### 1.2 在线学习平台

公司为全员开通在线学习平台账号，提供专业课程、通用课程与认证学习路径，员工可自主学习并计入学习记录。

### 1.3 外部培训与考证

- 与岗位相关的外部培训、行业大会、职业认证，员工可提交「培训申请」，经主管与 HR 审批后参加；
- **考证补贴**：员工考取与岗位相关的职业证书（如 PMP、信息系统项目管理师、注册会计师、法律职业资格、HR 相关证书等），考取后报销考试费及合理的培训费；
- 公司承担专项培训费用的，可依《劳动合同法》约定服务期（详见《01》第四节）。

## 二、职级体系

公司设双通道职级体系，员工可根据特长选择「专业通道」或「管理通道」发展，两条通道职级等效、薪酬带宽对应。

### 2.1 双通道

```
专业通道（P）          管理通道（M）
P3  初级               
P4  中级               
P5  高级               M1  主管
P6  资深 / 专家         M2  经理
P7  专家 / 高级专家     M3  高级经理 / 部门负责人
P8  首席专家            M4  总监
                       M5  VP
```

- **专业通道（P）**：适合愿意深耕专业、不带团队的员工，靠专业影响力发展；
- **管理通道（M）**：适合愿意带团队、负责团队产出的员工；
- 两条通道可双向转换，转换需符合相应通道的能力要求并经评估。

### 2.2 各序列职级

研发、产品、运营、职能等序列均适用统一职级框架，各序列有对应的能力标准（任职资格）。

## 三、晋升机制

### 3.1 晋升周期

公司每年组织 **2 次**晋升评审（与半年度绩效周期对应，一般在 2 月、8 月）。

### 3.2 晋升基本条件

申请晋升一般应满足：

1. **司龄/在职级时间**：在当前职级工作满一定时间（一般 P3→P4 满 1 年，P4→P5 满 1.5 年，P5 及以上满 2 年，具体以序列标准为准）；
2. **绩效要求**：最近 2 个考核周期绩效均不低于 B，且至少 1 次为 A 及以上；
3. **能力达标**：达到目标职级的任职资格能力标准；
4. **无重大违纪**：评审周期内无违纪记录、无未结的绩效改进计划。

### 3.3 晋升流程

```
员工/主管发起 → 主管推荐 → 准备晋升材料 → 晋升答辩/评审 → 评审委员会决议 → 结果公示 → 晋升生效
```

1. 由员工本人或直接主管发起晋升提名；
2. 直接主管出具推荐意见，员工准备晋升述职材料（业绩、能力佐证）；
3. 跨部门评审委员会进行答辩或材料评审；
4. 评审委员会综合表现做出晋升决议；
5. 结果在部门内公示，无异议后晋升生效，同步进行晋升调薪（详见《04》）。

### 3.4 晋升结果应用

- 晋升通过：职级、薪酬带宽相应调整，调薪随晋升生效月起算；
- 晋升未通过：评审委员会给出未通过原因与发展建议，员工可在下个周期重新申请。

## 四、横向发展与内部转岗

公司鼓励员工在内部探索更适合的岗位：

- **内部转岗**：员工在本岗位工作满一定时间（一般试用期通过后满 1 年），可申请内部转岗；
- 转岗需经现部门、目标部门与 HR 三方评估，确保平稳交接；
- 内部活水优先于外部招聘，员工内部转岗的，原司龄、年假、社保等连续计算，无需重新计算试用期（但可设观察期）。

## 五、导师制

- 新员工入职即配备一名导师（Mentor），由部门内有经验的同事担任；
- 导师在新员工入职 3 个月内提供业务指导、答疑与文化融入支持；
- 公司对优秀导师给予认可与激励。

## 六、人才盘点与发展计划

- 公司每年结合绩效进行人才盘点，识别高潜人才；
- 高潜人才纳入重点发展计划，提供更多培训资源、轮岗或挑战性项目机会；
- 绩效待改进员工纳入绩效改进计划（PIP，详见《05》）。

## 七、常见问题

**Q：多久能晋升一次？**
A：公司每年组织 2 次晋升评审（约 2 月、8 月）。能否晋升取决于在职级时间、绩效、能力达标情况，不是「到点就升」。

**Q：晋升要满足什么条件？**
A：在当前职级满规定时间、最近 2 个考核周期绩效不低于 B 且至少 1 次 A、达到目标职级任职资格、无重大违纪。

**Q：我不想带团队还能晋升吗？**
A：可以。公司有专业通道（P）和管理通道（M），不带团队走专业通道一样可以晋升，两条通道职级和薪酬带宽对应。

**Q：考证公司给报销吗？**
A：与岗位相关的职业证书，考取后可报销考试费和合理的培训费，需事前提交培训申请审批。

**Q：我想换个岗位，可以内部转岗吗？**
A：可以。试用期通过后在本岗位满 1 年一般可申请内部转岗，需现部门、目标部门和 HR 三方评估。转岗后司龄、年假连续计算。
