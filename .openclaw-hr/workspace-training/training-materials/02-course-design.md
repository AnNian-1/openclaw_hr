# 02-课程设计：新员工培训 · AI 大模型应用开发岗位

> **AI 辅助生成，讲师审核后交付**

## 一、课程总体结构

| 环节 | 模块 | 时长 | 教学方式 |
|---|---|---|---|
| 第一天上午 | 模块 1：走进星桥科技（公司通识） | 1.5h | 讲授 + 案例 + 问答 |
| | 模块 2：公司产品体系与技术架构 | 2h | 讲授 + 系统演示 |
| 第一天下午 | 模块 3：开发环境搭建与规范 | 1.5h | 实操 + 现场辅导 |
| | 模块 4：大模型应用开发基础 | 2.5h | 讲授 + 代码 Demo + 实操 |
| 第二天上午 | 模块 5：RAG 与知识增强实战 | 3h | 实操 + 小组协作 |
| 第二天下午 | 模块 6：大模型应用优化与安全合规 | 2h | 案例分析 + 研讨 |
| | 总结与评估（测试 + 反馈） | 1h | 测试 + 填写反馈表 |

**总有效教学时长：12 小时（不含午休）**

## 二、模块详细设计

### 模块 1：走进星桥科技（1.5h）

| 项目 | 内容 |
|---|---|
| **时长** | 1.5h（讲授 60min + 问答 30min）|
| **培训目标** | T1 |
| **内容要点** | ① 公司发展历程与行业定位；② 组织架构与五大中心；③ 使命与价值观（客户第一、务实诚信、持续学习、协作共赢、拥抱变化）；④ 新员工权益速览（工作时间、办公模式、企业 IM、HR 数字员工小慧）；⑤ 培训体系与双通道职级晋升机制；⑥ 导师制与入职 90 天路线图 |
| **教学方式** | 讲授 + 问答互动 |
| **教学材料** | 《公司简介与组织架构》《培训与晋升通道》《入职流程》三份材料汇编 |

### 模块 2：公司产品体系与技术架构（2h）

| 项目 | 内容 |
|---|---|
| **时长** | 2h（讲授 80min + 系统演示 40min）|
| **培训目标** | T2 |
| **内容要点** | ① 「星桥协同云」产品功能与用户场景；② 「星桥数据洞察」产品与数据智能特色；③ 后端技术栈概览（微服务架构、消息队列、数据库方案、API 网关）；④ 大模型在公司产品中的定位与典型应用场景（智能助手、数据分析自然语言查询、文档摘要、知识库问答）；⑤ 现有 AI 基础设施（模型服务平台、推理 API、向量数据库） |
| **教学方式** | 讲授 + 产品系统实时演示 |
| **教学材料** | 产品 Demo 环境、架构图 |

### 模块 3：开发环境搭建与规范（1.5h）

| 项目 | 内容 |
|---|---|
| **时长** | 1.5h（实操 90min，讲师巡回辅导）|
| **培训目标** | T3 |
| **内容要点** | ① 代码仓库注册与权限申请（GitLab / GitHub Enterprise）；② 本地开发环境要求（Python 版本管理、pyenv / conda 推荐做法）；③ 项目仓库克隆与依赖安装（poetry / pip 规范）；④ API Key 与网关配置（模型推理服务接入方式）；⑤ Git 工作流与 Commit 规范；⑥ Code Review 流程与 PR 模板；⑦ 【实操】完成 Hello World 验证程序——调用公司 API 网关完成一次 LLM 推理并输出结果 |
| **教学方式** | 实操 — 讲师先演示核心步骤，学员跟做，讲师巡回辅导 |
| **教学材料** | 《AI 大模型开发环境配置指南》（随训提供）|

### 模块 4：大模型应用开发基础（2.5h）

| 项目 | 内容 |
|---|---|
| **时长** | 2.5h（讲授+代码 Demo 90min + 实操 60min）|
| **培训目标** | T4 |
| **内容要点** | ① LLM API 调用基础（Chat Completions、Streaming、参数调优）；② 提示工程基础（System Prompt / Few-shot / Chain-of-Thought）；③ 函数调用（Function Calling）与工具集成；④ 模型选型与成本考量（按场景选择模型大小 / 推理 vs 微调）；⑤ 【实操】用公司 API 网关封装一个「智能客户问答」接口 |
| **教学方式** | 边讲边写代码 Demo + 学员动手跟做 |
| **教学材料** | API 文档、代码片段模板 |

### 模块 5：RAG 与知识增强实战（3h）

| 项目 | 内容 |
|---|---|
| **时长** | 3h（讲授 60min + 实操 120min）|
| **培训目标** | T4 |
| **内容要点** | ① RAG 架构拆解（Indexing → Retrieval → Generation）；② 文档分块策略（Chunking 方法选择与实验）；③ 嵌入（Embedding）与向量数据库选型（Milvus / Chroma / pgvector）；④ 检索增强：语义检索 + 关键词混合检索（Hybrid Search）；⑤ 【实操：小组协作】完成一个「公司产品知识库问答」端到端 Demo：文档入库 → 检索 → 生成回答（使用公司内部产品文档作为语料）|
| **教学方式** | 小组式协作实操（3-4 人一组），讲师全程巡回辅导 |
| **教学材料** | 示例文档语料包、向量数据库本地环境、代码脚手架 |

### 模块 6：大模型应用优化与安全合规（2h）

| 项目 | 内容 |
|---|---|
| **时长** | 2h（案例分析 60min + 研讨 60min）|
| **培训目标** | T5 |
| **内容要点** | ① 生产环境常见问题分析——幻觉（Hallucination）检测与缓解策略、响应延迟优化（缓存、流式、模型蒸馏）、成本控制（Token 用量与模型选择策略）；② 安全合规要点——数据脱敏（PII 识别与过滤）、内容安全审核、Prompt 注入防护、合规红线（客户数据不得外传至第三方大模型）；③ 【案例研讨】给出三个真实场景案例（客服智能回复产生幻觉 / 用户输入注入尝试 / 成本超限预警），各组分析问题根因并提出优化方案 |
| **教学方式** | 案例分析 + 小组讨论 + 展示 |
| **教学材料** | 案例材料（脱敏版）|

### 总结与评估（1h）

| 项目 | 内容 |
|---|---|
| **时长** | 1h（测试 40min + 反馈 20min）|
| **培训目标** | T1–T5（综合考核）|
| **内容** | ① 课后测试（单选+多选+简答）；② 填写培训评估反馈表；③ 讲师总结与 Q&A |
| **教学方式** | 测试 + 匿名问卷 |

## 四、教学方式分布

| 教学方式 | 总时长 | 占比 |
|---|---|---|
| 讲授（含系统演示）| 约 4.5h | 35% |
| 实操 / 动手练习 | 约 5.5h | 43% |
| 案例研讨 / 小组讨论 | 约 2h | 16% |
| 测试与反馈 | 约 1h | 8% |

> 实操占比最高（43%），体现 AI 大模型开发岗位「动手实践型」学习特征。
