## 一、单选题（每题 6 分，共 36 分）

### 第 1 题（基础 · 【对应培训目标 T1】）

星桥科技的使命是什么？

A. 让世界因为数据更美好
B. 用数据智能让企业管理更高效
C. 成为全球最大的 SaaS 平台
D. 让每一个中小企业都用上 AI

**正确答案：B**

**解析**：星桥科技的使命是"用数据智能让企业管理更高效"（见《公司简介》）。A 选项是常见的"美化型"表述但不是星桥官方的；C 选项"全球最大"夸大了公司定位；D 选项"中小企业"虽是目标客户但表述不准确。

### 第 2 题（基础 · 【对应培训目标 T1】）

以下关于星桥科技双通道职级体系的描述，正确的是：

A. 专业通道（P）最高只能到 P6
B. 管理通道（M）不能转为专业通道（P）
C. 专业通道与管理通道职级等效、薪酬带宽对应
D. 只有管理通道的员工才能晋升到总监级别

**正确答案：C**

**解析**：公司实行双通道职级体系，P 通道和 M 通道职级等效、薪酬带宽对应。A 错误：专业通道最高到 P8（首席专家）；B 错误：两条通道可双向转换；D 错误：走专业通道一样可以晋升到高级别。

### 第 4 题（中等 · 【对应培训目标 T3】）

关于公司 API Key 与开发环境配置，以下做法正确的是：

A. 将 API Key 直接写在 Python 脚本中，方便其他同事复用
B. 将 API Key 配置在 `.env` 文件中，并且将 `.env` 添加到 `.gitignore`
C. 为了方便，直接 push main 分支部署测试
D. 使用默认 `temperature=1.0` 确保输出多样性

**正确答案：B**

**解析**：API Key 属于敏感凭据，应放在 `.env` 文件中并通过 `.gitignore` 避免提交到 Git 仓库。A 错误：写在代码中导致凭据泄露；C 错误：禁止直接 push 到 main；D 错误：temperature=1.0 输出随机性过高。

### 第 5 题（中等 · 【对应培训目标 T4】）

以下哪种 Prompt 设计策略最适合降低大模型生成"幻觉"的风险？

A. 提高 temperature 到 0.9，让模型更有创造性
B. 在 System Prompt 中加上"仅基于提供的材料内容回答，如果没有足够信息就回答不知道"
C. 使用更短的 prompts，不给模型太多上下文
D. 每次都使用最大 max_tokens 值

**正确答案：B**

**解析**：在 System Prompt 中加入行为约束是减少幻觉最直接有效的方式。A 错误：高 temperature 会增加不确定性；C 错误：过短 prompt 缺少约束；D 错误：max_tokens 过大增加成本。

### 第 6 题（中等 · 【对应培训目标 T5】）

新上线的一款 AI 功能 Token 消耗远超预算，以下哪个是最不可能的原因？

A. 某个用户的 Bot 在循环调用，且未设置调用频率限制
B. `max_tokens` 值设得太大，导致单次调用生成大量 Token
C. 使用了缓存策略，大部分请求命中缓存
D. 模型选用了 GPT-4 处理本可以用小模型完成的简单任务

**正确答案：C**

**解析**：缓存策略能减少重复查询对 LLM 的调用次数，从而**降低** Token 消耗。A（循环调用无限制）、B（max_tokens 过大）、D（大材小用）都是成本超限的典型原因。

## 二、多选题（每题 10 分，共 20 分）

### 第 7 题（中等 · 【对应培训目标 T2、T4】）

以下关于 RAG（检索增强生成）的描述，正确的有：

A. RAG 的三步流程是：Indexing → Retrieval → Generation
B. RAG 可以完全消除大模型的所有幻觉问题
C. 分块（Chunking）的大小和策略对检索质量有显著影响
D. 语义检索 + 关键词检索（混合检索）可以提升召回质量

**正确答案：A、C、D**

**解析**：A 正确——RAG 的标准流程。B 错误——RAG 能大幅减少幻觉但不能完全消除。C 正确——分块策略直接影响检索结果准确性。D 正确——混合检索结合语义和关键词的优势。

### 第 8 题（应用 · 【对应培训目标 T5】）

以下哪些措施可以有效防止大模型应用中的 Prompt 注入攻击？

A. 将用户输入与 System Prompt 在结构上物理分隔（如使用分隔标记）
B. 对用户输入进行过滤，移除明显的注入指令模式
C. 允许用户直接修改 System Prompt
D. 对模型输出进行校验，检查是否泄露了系统指令或敏感信息

**正确答案：A、B、D**

**解析**：A 正确——输入输出分隔是最基本的 Prompt 注入防护手段。B 正确——输入过滤可以拦截常见注入模式。C 错误——允许用户修改 System Prompt 等于放弃控制。D 正确——输出校验可以检测注入是否成功。

## 三、简答题（每题 22 分，共 44 分）

### 第 9 题（应用 · 【对应培训目标 T4】）

**题目**：请设计一个简单的 RAG 检索增强生成流程的用户提问处理函数。要求：
1. 描述该函数的输入、处理步骤和输出（8 分）
2. 给出关键步骤的伪代码或思路（8 分）
3. 说明为什么 RAG 比直接让 LLM 回答更有效（6 分）

**参考答案**：

**（1）函数设计与步骤（8 分）**

- **输入**：用户问题（字符串）、可选的历史对话记录
- **处理步骤**：① 对用户问题进行 Embedding，生成向量表示；② 用该向量检索向量数据库，获取最相关的 k 个文档片段；③ 将检索到的文档片段 + 用户问题组合成 Prompt；④ 调用 LLM 生成回答（要求附引用来源）
- **输出**：回答内容 + 引用的文档来源

**（2）伪代码思路（8 分）**

```python
def rag_answer(question, k=3):
    q_embedding = embedding_model.encode(question)
    results = vector_db.similarity_search(q_embedding, k=k)
    context = "\n\n".join([r.content for r in results])
    prompt = f"基于以下文档回答问题。无相关信息则说找不到。\n\n{context}\n\n问题：{question}"
    answer = llm.generate(prompt)
    return {"answer": answer, "sources": [r.source for r in results]}
```

**评分要点**：完整流程（4 分）；设置 k 值和引用来源（2 分）；处理"找不到"情况（2 分）；伪代码关键步骤（8 分）

**（3）为什么 RAG 更有效（6 分）**
- 知识实时性：LLM 训练数据有截止日期，RAG 可引入最新文档（2 分）
- 减少幻觉：基于提供文档生成回答，非"凭记忆"（2 分）
- 可追溯：回答附引用来源，用户可验证（2 分）

### 第 10 题（应用 · 【对应培训目标 T3、T5】）

**题目**：作为一名新入职的 AI 大模型应用开发工程师，你被分配升级"星桥协同云"智能助手。请列出：
1. 入职后需要完成哪些环境和技术准备工作（6 分）
2. 做产品级 AI 功能时，需要考虑哪三个方面的优化/安全措施（12 分）
3. 上线后发现成本飙升，怎么排查和解决（4 分）

**参考答案**：

**（1）环境与准备工作（6 分）**
- 完成开发环境配置（Python、Git、Docker），配置 API Key 和模型网关（2 分）
- 加入项目 GitLab 仓库，阅读 README 和现有代码结构（2 分）
- 理解现有智能助手流程，了解产品文档存储位置（2 分）

**（2）优化与安全措施（12 分，至少 3 个方面，每个 4 分）**
- **方面一：回答质量（减少幻觉）** ——实施 RAG 架构，Prompt 约束"仅基于提供材料回答"，输出附引用来源
- **方面二：响应速度**——开启 Streaming，实施语义缓存
- **方面三：数据安全合规**——PII 脱敏，Prompt 注入防护，审计日志
- **方面四：成本控制（加分）**——模型分级路由，监控告警

**（3）成本飙升排查与解决（4 分）**
- 查看审计日志和监控看板，找出 Token 消耗最高的用户、模型和时段（1 分）
- 用户 Bot 循环调用→添加频率限制和用量上限（1 分）
- 全部用 GPT-4→实施模型分级路由（1 分）
- max_tokens 或 prompt 过长→优化 prompt，合理设置 max_tokens（1 分）
