# 公司文化与规章制度 新员工入职培训 交付指南

## 一、 物料清单（培训包组成）

一套完整的、可交付的培训包应包含以下8份文件。讲师在接收到此套材料后，请首先核对清单是否完整。

1.  **课程需求分析**：`01-needs-analysis.md`
    *   **用途**：理解培训目标、受众及背景，确保授课时内容传递紧扣核心目标。
2.  **课程设计方案**：`02-course-design.md`
    *   **用途**：掌握课程的整体结构、模块划分、时间分配与教学方式，是授课的蓝图。
3.  **PPT大纲与指引**：`03-ppt-outline.md`
    *   **用途**：作为制作最终授课PPT的详细大纲和结构依据。所有关键内容点均已列出。
4.  **讲师手册**：`04-instructor-manual.md`
    *   **用途**：**核心授课指南**。详细说明每一页PPT的讲解要点、互动引导、控场建议与讲师提示。这是讲师备课和现场执行的主要依据，**非逐字稿**。
5.  **学员手册**：`05-participant-handbook.md`
    *   **用途**：培训现场发放给学员的教材，内容涵盖课程核心、实用工具与FAQ，也是学员的快速参考指南。
6.  **课后测试题**：`06-assessment.md`
    *   **用途**：用于培训结束后评估学员学习效果，巩固知识。可在培训结束时现场进行或作为课后作业。
7.  **交付指南（本文件）**：`07-delivery-guide.md`
    *   **用途**：指导讲师如何“组装”和运用以上材料，完成从准备到评估的全流程。
8.  **最终PPT课件**（待制作）
    *   **用途**：根据 `03-ppt-outline.md` 和公司统一视觉规范制作完成的、用于现场演示的PPT文件。

## 二、 培训前、中、后实施流程

### 阶段一：培训前（准备阶段，D-3至D-1）
1.  **材料确认与熟悉**：
    *   核对上述8份物料清单，确保完整。
    *   精读《讲师手册》，重点关注“课前准备清单”及各模块的讲解要点。
    *   通读《学员手册》，了解学员将获取的信息视角。
2.  **内容与工具准备**：
    *   根据《PPT大纲》，结合《讲师手册》要点，准备好最终授课PPT（或确认最终版PPT）。
    *   提前测试授课场地的投影、音响、麦克风设备。
    *   **关键动作**：提前登录HR数字员工“小慧”，模拟查询（如“年假规则”），确保网络通畅、账号正常、响应流畅。
3.  **行政协调**：
    *   确认培训时间、地点，并通知HR及所有参训新员工。
    *   准备学员签到表。
    *   打印足量的《学员手册》、《课后测试题》。
4.  **新讲师准备（若适用）**：
    *   参照下文“新讲师上手路径”进行准备和练习。

### 阶段二：培训中（执行阶段，D-Day）
1.  **开场（模块一）**：
    *   按《讲师手册》指引完成开场，建立积极、专业的基调。
    *   分发《学员手册》，告知学员其用途。
2.  **核心授课（模块一至五）**：
    *   严格按照《课程设计》的时间表和《讲师手册》的指引推进。
    *   灵活运用讲解、互动、演示等多种教学方式。
    *   **在模块三（核心规章制度）**，务必进行“小慧”查询的现场演示，并留出足够时间让学员实操。
    *   随时关注学员反应，调整语速和互动频率。
3.  **总结与测试（模块五后）**：
    *   完成“课程总结与答疑”环节，引导学员回顾核心要点。
    *   根据安排，发放并回收《课后测试题》（可现场作答，也可课后完成）。
4.  **结尾**：
    *   表达欢迎与祝福，收集学员对课程的简单口头反馈。

### 阶段三：培训后（跟进阶段，D+1至D+7）
1.  **反馈与评估**：
    *   阅读《课后测试题》结果，了解学员知识掌握情况，识别共性薄弱点。
    *   整理培训中收集的学员问题与反馈。
2.  **资料归档与反馈**：
    *   将培训记录（签到表、测试结果、反馈摘要）提交给HR部门存档。
    *   将需要后续解答的问题反馈给HR相关部门（如员工关系、OD&T）。
3.  **内容迭代**：
    *   根据本轮培训的反馈和公司政策的更新，向课程设计者提出优化《学员手册》、《PPT大纲》或《讲师手册》的建议。

## 三、 新讲师上手路径

为首次授课的新讲师设计的四步上手法：

1.  **第一步：通读与理解（1-2小时）**
    *   **任务**：静心阅读《需求分析》和《课程设计》，理解“为什么讲”和“讲什么”。
    *   **产出**：在脑海中形成课程的整体框架和逻辑脉络。
2.  **第二步：精研与备课（3-4小时）**
    *   **任务**：逐页精读《讲师手册》，并与《PPT大纲》对应。重点理解每页的“讲解要点”和“讲师提示”。
    *   **练习**：根据“讲解要点”，用自己的语言组织每一页的讲解内容，可尝试出声演练。**切忌背诵**。
    *   **产出**：一份属于自己的、基于手册要点的个性化讲课提纲。
3.  **第三步：试讲与演练（1-2小时）**
    *   **任务**：对着PPT或白板进行完整试讲，模拟真实授课过程，包括互动环节。
    *   **练习**：计时，确保每部分时间控制在计划内（参考《PPT大纲》建议时长）。重点演练“小慧”演示环节。
    *   **产出**：完成一次完整的模拟授课，并记录下需要调整的环节。
4.  **第四步：复核与准备（课前1天）**
    *   **任务**：进行最后一次全流程复核。
    *   **检查**：确认PPT、设备、“小慧”账号均已就绪。再次翻阅《讲师手册》中的“课前准备清单”和“培训当天checklist”。
    *   **产出**：心态和物料上的充分准备，迎接正式授课。

## 四、 培训当天 Checklist

### 讲师 Checklist（授课前30分钟）
- [ ] **设备检查**：电脑开机，PPT播放正常；投影、音响、麦克风测试OK；激光笔电量充足。
- [ ] **环境检查**：桌椅摆放符合互动需求；室温适宜；走道畅通，便于巡视。
- [ ] **材料准备**：打印版《学员手册》、《课后测试题》、签到表、笔。
- [ ] **工具实测**：打开“小慧”，进行一次查询测试，确认网络与账号稳定。
- [ ] **自我准备**：快速回顾课程开场及前两个模块的讲解要点。

### 学员接待 Checklist（学员入场至课程开始）
- [ ] 引导学员签到。
- [ ] 发放《学员手册》。
- [ ] 提醒课程时长、中间休息安排及手机静音。
- [ ] 开场前播放公司宣传视频或暖场音乐（若需）。

## 五、 常见问题处理预案

1.  **问题：现场人数远超预期（如场地容纳不下）**
    *   **预案**：
        *   **立即行动**：与HR组织者协调，申请更换至更大的会议室，或启动备用场地。
        *   **临时方案**：若无法更换，可迅速调整座位布局（如减少小组讨论，改为剧院式），并立即与HR沟通，承诺为本次未参训人员安排后续补充培训。
        *   **讲师沟通**：向学员坦诚说明情况，并表达将全力保证课程质量的承诺。

2.  **问题：课程进度严重落后**
    *   **预案**：
        *   **动态调整**：在模块切换时（如过渡页），评估剩余时间和内容。如果落后15分钟以上，需果断决策。
        *   **优先级管理**：优先确保**模块三（规章制度，尤其是查询方法）** 和**模块五（入职流程）** 的核心内容讲授到位。
        *   **灵活压缩**：对**模块二（组织架构）** 和**模块四（职业发展）** 中的次要点（如各中心详细职能、四类培训体系）进行快速概述，或将其留给学员自学。
        *   **互动优化**：将较长的小组讨论简化为快速问答或讲师分享。
        *   **沟通**：若需大幅调整，可向学员简要说明：“为确保最重要的内容讲清，我们将对后续模块进行一些调整。”

3.  **问题：关键设备（投影、电脑）故障**
    *   **预案**：
        *   **备用方案**：确保培训包中有打印版的《PPT大纲》（含要点）。
        *   **临时教学**：立即启动“无PPT模式”。依据《讲师手册》的要点，结合《学员手册》进行讲解。可以走到学员中间，使用白板、 flipchart 或口头描述。
        *   **技术求助**：安排一位学员或现场工作人员（如IT支持）立即联系维修，讲师继续授课。

4.  **问题：学员参与度低（不愿互动、气氛沉闷）**
    *   **预案**：
        *   **营造安全氛围**：开场时强调“本课程是帮助大家，没有蠢问题”，鼓励分享。
        *   **互动技巧**：将直接提问改为“二选一”选择题，或邀请“那位还没发言的同事分享一下看法”。
        *   **改变形式**：将大范围提问转为小组讨论（2-3人），然后请小组代表汇报。
        *   **价值链接**：在互动前，强调“这个问题与你下周的报销/你三年内的晋升直接相关”，提升参与动力。

5.  **问题：学员就具体个案政策提出尖锐或超出范围的问题**
    *   **预案**：
        *   **原则**：不现场解读可能变动的具体条款或案例。
        *   **标准回应**：“这是一个很好的具体问题。根据我们强调的原则，最准确的回答可以在我们刚刚演示的官方渠道（‘小慧’或知识库）中找到。我建议你课后尝试查询‘XXX政策’，如果仍有疑问，可以联系HR员工关系组（写在你的学员手册里）获得针对性的解答。课程后我也可以帮你记录这个问题并反馈给HR。”
