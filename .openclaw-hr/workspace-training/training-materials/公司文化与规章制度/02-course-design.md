# 公司文化与规章制度 新员工入职培训 课程设计

## 一、课程总体结构
本课程为**入职首周必修培训**，旨在系统化、结构化地帮助新员工建立对公司文化、制度与发展通道的认知框架。课程采用“讲解+互动+工具实操”的混合式教学，总时长约**3小时**，分为五个模块。

## 二、模块详细设计

### 模块一：公司概览与文化（时长：30分钟）
- **目标**：建立对公司的整体认知，理解并认同核心价值观。
- **内容点**：
    1.  公司简介：成立时间、主营业务、发展阶段。
    2.  使命与愿景：阐述公司存在的意义和长远目标。
    3.  核心价值观详解：逐条解释“客户第一/务实诚信/持续学习/协作共赢/拥抱变化”的内涵与行为体现。
- **教学方式**：讲师讲解、价值观场景化提问互动。

### 模块二：组织架构与部门职能（时长：30分钟）
- **目标**：了解公司主要架构和各部门核心职能，知道业务协作关系。
- **内容点**：
    1.  CEO负责制与五大中心体系。
    2.  各中心（研发、产品、商业化、职能、战略与运营）的职责概述。
    3.  HR部门四大模块（招聘、人事薪酬、OD&T、员工关系）的职能介绍。
    4.  「小慧」的角色与使用方式。
- **教学方式**：结合架构图讲解、问答（如：“如果你有关于社保的问题，应该找HR哪个组？”）。

### 模块三：核心规章制度（时长：40分钟）
- **目标**：知晓与日常工作相关的核心制度，并掌握查询方法。
- **内容点**：
    1.  工作制度：标准工时、办公模式、企业IM使用。
    2.  行为与合规准则：保密要求、廉洁从业等概述。
    3.  **重点**：如何查找制度——演示通过HR数字员工「小慧」、企业微信知识库、HR Helpdesk等渠道获取详细政策文档。
- **教学方式**：讲解重点条款、现场演示如何通过「小慧」查询一项政策（如年假规则）。

### 模块四：职业发展与支持（时长：40分钟）
- **目标**：明晰职业成长路径，了解公司提供的发展资源。
- **内容点**：
    1.  **双通道职级体系**：专业通道（P）与管理通道（M）的对比与转换。
    2.  **晋升机制**：晋升周期、基本条件（司龄、绩效、能力、违纪）、典型流程。
    3.  **培训与发展**：四类培训体系（入职、通用、专业、管理者）简介，外部培训与考证报销政策。
    4.  **内部流动**：内部转岗政策与流程。
    5.  **导师制**：导师的作用与期望。
- **教学方式**：讲师讲解、分享成功转岗或晋升的匿名案例、小组讨论（“你认为P通道和M通道最大的不同是什么？”）。

### 模块五：入职流程与支持资源（时长：40分钟）
- **目标**：清晰回顾入职流程，消除焦虑，掌握关键支持资源。
- **内容点**：
    1.  **报到当天关键步骤**：材料核验、合同签署、系统开通等，强调法律意义（如合同即时签订）。
    2.  **入职材料清单回顾**：强调各项材料用途及合规提示（禁止扣押证件、收取财物）。
    3.  **试用期管理**：试用期时长、考核标准、转正流程。
    4.  **支持资源汇总**：再次强调HR「小慧」、导师、部门主管的作用。
- **教学方式**：流程图讲解、常见问题（FAQ）快问快答、重申支持渠道。

## 四、教学方式分布
- **讲授式**：约50%，用于传递核心概念、流程和政策。
- **互动式**：约35%，包括提问、小组讨论、案例分析，促进理解与反思。
- **工具实操式**：约15%，演示并让学员体验使用「小慧」等查询工具。
