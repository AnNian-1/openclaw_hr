# 公司文化与规章制度 新员工入职培训 讲师手册

**手册说明**
本手册是授课指南，非逐字讲解稿。旨在帮助讲师明确每一页PPT的核心讲解思路、互动设计与控场建议。讲师应依据本手册的“讲解要点”组织语言，结合现场氛围灵活发挥。请务必在课前通读并备课。

## 课前准备清单
1.  **材料核对**：确认PPT最终版已拷贝至授课设备。
2.  **工具测试**：提前登录HR数字员工“小慧”，确保演示时网络畅通、响应正常。
3.  **环境检查**：确认会议室投屏、音响、麦克风正常，互动环节（如现场问答）的走位无阻碍。
4.  **时间预估**：本课程总设计时长约3小时10分钟，课间休息需自行安排（建议模块间安排短休）。
5.  **备稿原则**：依据本手册的“讲解要点”自行准备讲述语言，避免照念。

---
## PPT 逐页讲解指南

### 第1页：封面：公司文化与规章制度
- **页码标题**：1 - 封面
- **建议时长**：1分钟
- **讲解要点**：
    - 欢迎新同事加入公司。
    - 点明本课程是入职必修课，目标是帮助大家“顺利启航”。
    - 简要介绍课程将涵盖文化、架构、制度、发展与实操五个模块。
- **互动引导**：无。
- **讲师提示**：开场简短有力，建立积极、专业的基调。控制在1分钟内，不宜展开。

### 第2页：课程目录
- **页码标题**：2 - 课程目录
- **建议时长**：1分钟
- **讲解要点**：
    - 清晰介绍课程将按五大模块顺序进行。
    - 强调模块间的逻辑关系：先理解文化与架构（我们是谁），再学习制度与规范（如何共事），最后了解发展与实操（如何成长与支持）。
    - 让学员对课程脉络有整体预期。
- **互动引导**：无。
- **讲师提示**：快速过页，指明当前模块即可，不要在此页深入讲解模块内容。

### 第3页：过渡页：从理解到践行：我们的公司文化
- **页码标题**：3 - 过渡页（模块一）
- **建议时长**：0.5分钟
- **讲解要点**：
    - 明确模块一的目标：帮助大家建立对公司的整体认知，并理解文化价值观的内涵。
    - 提出引导性问题：“我们因何存在？向往何处？如何共事？”，引发思考。
- **互动引导**：无。
- **讲师提示**：这是一个思维过渡，语气应带有引导性，为后续内容做铺垫。

### 第4页：公司简介：我们是谁
- **页码标题**：4 - 公司简介
- **建议时长**：2分钟
- **讲解要点**：
    - 介绍公司定位（SaaS与数据智能服务）与发展阶段（规模化增长）。
    - 说明核心业务是为客户提供解决方案。
    - 点出服务载体示例：HR数字员工“小慧”，建立初步印象。
- **互动引导**：可询问：“有同事听说过‘小慧’吗？”了解学员认知度。
- **讲师提示**：介绍力求精炼、形象。若公司有更具体或知名的业务案例，可简单补充，但避免冗长。

### 第5页：使命与愿景：我们为何在此
- **页码标题**：5 - 使命与愿景
- **建议时长**：3分钟
- **讲解要点**：
    - **讲师此处需根据公司实际情况填入具体使命与愿景内容。**
    - 解释使命是公司存在的根本意义（Why），愿景是长远的目标与蓝图（Where）。
    - 强调使命和愿景是所有工作的方向指引，连接个体与公司的目标。
- **互动引导**：无。
- **讲师提示**：**本页内容关键且易错。讲师务必提前确认公司最新的、官方的使命与愿景表述，不可现场杜撰或模糊处理。** 讲解时需传递出对使命愿景的认同感。

### 第6页：核心价值观详解（1）
- **页码标题**：6 - 核心价值观详解（1）
- **建议时长**：6分钟
- **讲解要点**：
    - **客户第一**：内涵是“以客户成功为中心”。行为体现举例：当客户有紧急需求时，优先响应并协调内部资源。
    - **务实诚信**：内涵是“踏实做事，诚实守信”。行为体现举例：在汇报项目进展时，既报喜也报忧，不隐瞒风险。
    - 每条价值观先讲内涵，再举一个贴近工作的行为例子。
- **互动引导**：可提问：“结合你过往的经历，你认为‘客户第一’在实际工作中可能体现在哪些方面？”
- **讲师提示**：这是价值观讲解的第一页，时长较长。注意节奏，不要在前两项上投入过多时间而影响后续内容。举例应具体，避免空泛。

### 第7页：核心价值观详解（2）
- **页码标题**：7 - 核心价值观详解（2）
- **建议时长**：5分钟
- **讲解要点**：
    - **持续学习**：内涵是“拥抱新知，自我驱动”。行为体现举例：主动利用公司培训资源、向同事请教、参与分享会。
    - **协作共赢**：内涵是“开放合作，共担共享”。行为体现举例：在跨部门项目中，主动沟通、明确接口，以项目成功为共同目标。
- **互动引导**：无。
- **讲师提示**：此页同样需控制时间，与上一页保持连贯。讲解时可与上页的“务实诚信”形成对比，突出不同价值观的侧重点。

### 第8页：核心价值观详解（3）
- **页码标题**：8 - 核心价值观详解（3）
- **建议时长**：5分钟
- **讲解要点**：
    - **拥抱变化**：内涵是“主动适应，积极创新”。行为体现举例：当业务方向调整时，快速学习新知识，调整工作方法。
    - 回顾并总结全部五项价值观，强调它们是一个整体，共同指引我们的行为。
    - 完成互动提问。
- **互动引导**：**正式互动环节**：“请列举一个你过往经历中体现‘务实诚信’的例子。”邀请1-2位学员分享。
- **讲师提示**：此页包含最后一条价值观和互动。时间充裕则深入讨论，时间紧张则快速总结并点出互动问题让学员思考，不一定要分享。互动重在引发思考。

### 第9页：过渡页：认识我们的组织与支持
- **页码标题**：9 - 过渡页（模块二）
- **建议时长**：0.5分钟
- **讲解要点**：
    - 明确模块二目标：了解公司的组织运转骨架，知道遇到问题该找谁。
    - 提出引导性问题：“公司如何分工？我的团队在哪里？”
- **互动引导**：无。
- **讲师提示**：平稳过渡，承上启下。

### 第10页：公司组织架构全景图
- **页码标题**：10 - 组织架构图
- **建议时长**：5分钟
- **讲解要点**：
    - 介绍总体结构为CEO负责制。
    - 重点讲解五大中心体系的名称（研发、产品、商业化、职能、战略与运营）及其存在意义。
    - 结合架构示意图，让学员对公司的骨架有宏观印象。
- **互动引导**：可提问：“大家看到这个架构图，觉得自己所在的团队或即将加入的团队，大概属于哪个中心？”
- **讲师提示**：架构图信息量大，讲解时不要陷入具体部门名称的罗列。重在建立“中心-部门-团队”的层级概念。建议配合激光笔逐步指认。

### 第11页：各中心核心职能
- **页码标题**：11 - 各中心核心职能
- **建议时长**：6分钟
- **讲解要点**：
    - 分别简要阐述五大中心的核心职能（如PPT所列）。
    - 强调各中心之间是“支撑”与“协同”关系，共同推动公司发展。
    - 可用一句通俗的话总结每个中心的价值。
- **互动引导**：无。
- **讲师提示**：此页是上一页的展开。讲解要快，每个中心用1分钟左右点明其“做什么”和“价值是什么”即可，避免展开到具体业务细节。

### 第12页：HR部门职能与「小慧」
- **页码标题**：12 - HR职能与「小慧」
- **建议时长**：8分钟
- **讲解要点**：
    - 分解HR四大模块（招聘、人事薪酬、OD&T、员工关系），说明各自核心工作。
    - **重点介绍HR数字员工「小慧」**：定位是7×24小时智能服务助手，用于政策查询、流程指引。
    - 说明“小慧”的访问方式（企业微信等）。
    - 强调“小慧”是员工自助解决问题的第一入口。
- **互动引导**：可问：“如果半夜突然想知道公司的年假规则，除了给HR同事留言，还有什么办法？”引导出“小慧”。
- **讲师提示**：本页内容多且实用。讲解HR模块时不必逐条解释，概括要点即可。**重点是让学员记住“小慧”这个工具，并知道它能解决什么问题。**

### 第13页：互动问答
- **页码标题**：13 - 互动问答
- **建议时长**：5分钟
- **讲解要点**：
    - 本页是模块二的知识检验与巩固。
    - 根据PPT问题示例，结合刚刚讲解的HR模块职能进行提问。
- **互动引导**：**正式互动环节**：
    1.  “如果你有关于社保缴纳的问题，应该找HR的哪个组？”（答案：人事薪酬）
    2.  “如果你想了解公司的培训课程，除了问主管，还可以找谁或什么工具？”（答案：OD&T模块或HR数字员工“小慧”）
- **讲师提示**：这是检验学员理解程度的好机会。给予思考时间，鼓励学员抢答。答对可简要表扬。若答错，不直接纠正，而是引导其回顾前面内容。

### 第14页：过渡页：日常工作制度与行为规范
- **页码标题**：14 - 过渡页（模块三）
- **建议时长**：0.5分钟
- **讲解要点**：
    - 明确模块三目标：知晓核心制度，并掌握查询制度详情的方法。
    - 提出引导性问题：“公司有哪些基本规则？规则在哪看？”
- **互动引导**：无。
- **讲师提示**：语气可略微强调，引导学员关注“如何获取信息”这一方法论。

### 第15页：工作制度概要
- **页码标题**：15 - 工作制度概要
- **建议时长**：6分钟
- **讲解要点**：
    - 简要说明标准工时、办公模式（主要办公地点与远程政策）、企业IM使用规范等基本制度。
    - 强调这些是确保公司高效、有序运转的基础。
    - 告知学员，具体、详细的条款在后续会讲解如何查询。
- **互动引导**：无。
- **讲师提示**：本页概述即可，重点是“点到为止”，避免陷入对考勤、打卡等具体条款的详细解释。详细内容引导至后续“查找制度”环节。

### 第16页：行为与合规准则
- **页码标题**：16 - 行为与合规准则
- **建议时长**：6分钟
- **讲解要点**：
    - 重点讲解保密要求、廉洁从业、职场行为这三条底线准则的内涵和重要性。
    - **务必提示**：所有准则的详细解释见公司正式制度文件（如员工手册）。
    - 这些是公司文化的红线，也是每位员工的职业操守。
- **互动引导**：可问：“大家觉得，为什么‘保密’和‘廉洁’对一家数据智能公司尤为重要？”
- **讲师提示**：此部分内容严肃。讲解时语气应郑重，强调其原则性和严肃性。避免展开讨论具体案例（除非培训要求），引导学员理解其必要性。

### 第17页：【重点】如何查找制度详情
- **页码标题**：17 - 查找制度详情
- **建议时长**：10分钟
- **讲解要点**：
    - **这是本模块的核心技能页。**
    - **官方渠道一：HR数字员工「小慧」**：现场演示如何提问（如输入“年假规则”），并展示其给出的回答与文档链接。
    - **官方渠道二：企业微信知识库/HR Helpdesk**：说明这是所有政策文档的最终归档地，可搜索查阅。
    - **核心原则**：遇到任何制度疑问，优先通过这两个官方渠道自助查询，这是最准确、高效的方式。
- **互动引导**：在演示后，可即兴提问：“如果我想知道出差报销的标准，可以怎么问？”
- **讲师提示**：**本页务必进行现场操作演示，这是最具说服力的教学。** 演示时要慢，确保学员看清步骤。强调“自助查询”的习惯能帮助大家快速解决问题。

### 第18页：工具实操：试试问「小慧」
- **页码标题**：18 - 工具实操
- **建议时长**：12分钟
- **讲解要点**：
    - 巩固上一环节，鼓励学员亲身体验。
    - 说明实操目的：熟悉工具界面和提问方式，建立对“自助查询”的信心。
    - 提供几个可尝试的问题方向。
- **互动引导**：**正式互动/实操环节**：“请大家现在拿出手机（或使用电脑），打开‘小慧’，试着问一个你关心的问题，比如试用期多长、怎么报销、信息安全规定是什么。”
- **讲师提示**：此环节是学员实践的关键时间。讲师应巡视，观察学员操作情况，及时给予个别指导。对于普遍性问题可集中讲解。确保大部分学员都完成至少一次有效查询。

### 第19页：过渡页：你的成长路径与发展支持
- **页码标题**：19 - 过渡页（模块四）
- **建议时长**：0.5分钟
- **讲解要点**：
    - 明确模块四目标：明晰个人成长路径，了解公司提供的发展支持。
    - 提出引导性问题：“我在这里如何成长？公司提供哪些支持？”
- **互动引导**：无。
- **讲师提示**：将话题从“规则”转向“发展”，提升学员的期待感。

### 第20页：双通道职级体系：P与M
- **页码标题**：20 - 双通道职级体系
- **建议时长**：8分钟
- **讲解要点**：
    - 清晰界定专业通道（P）和管理通道（M）的定义。
    - 讲解二者的核心区别：能力要求（深度vs广度）、价值产出（个人贡献vs团队产出）、发展导向（专家vs管理者）。
    - 说明P与M通道间可以转换，鼓励员工根据自身优势选择。
- **互动引导**：可问：“听完介绍，大家感觉自己的兴趣或优势可能更偏向哪个通道？”
- **讲师提示**：这是职业发展的核心概念。讲解时可使用比喻（如“登山”有两种路径），帮助理解。避免过度强调哪个通道更好，强调二者价值等同。

### 第21页：晋升机制
- **页码标题**：21 - 晋升机制
- **建议时长**：8分钟
- **讲解要点**：
    - 说明公司有固定的晋升评审周期（时间窗口）。
    - **重点讲解四个基本条件**：司龄、绩效、能力、纪律，缺一不可。
    - 简述典型流程（申请、评审、答辩、公示），让学员对流程有概念。
    - 强调晋升是水到渠成的结果，引导学员关注当下的绩效与能力提升。
- **互动引导**：无。
- **讲师提示**：四个条件是硬性要求，需清晰传达。但讲解时避免给学员“唯绩效论”的压力，应传递“持续成长，机会自来”的积极态度。

### 第22页：培训与发展资源
- **页码标题**：22 - 培训与发展资源
- **建议时长**：7分钟
- **讲解要点**：
    - 介绍公司四类培训体系（入职、通用、专业、管理），说明它们覆盖员工不同发展阶段。
    - 提及公司支持外部培训与考证，并有明确的报销政策。
    - 鼓励学员主动规划学习，利用公司资源。
- **互动引导**：可问：“大家最期待参加哪类培训？”
- **讲师提示**：列举资源类型即可，不必深入每项课程内容。重点传递“公司愿意投资于员工成长”的信息。

### 第23页：内部流动与导师制
- **页码标题**：23 - 内部流动与导师制
- **建议时长**：5分钟
- **讲解要点**：
    - **内部转岗**：说明公司政策是鼓励的，但需遵循流程（与双方部门沟通）。
    - **导师制**：强调导师是帮助新员工融入的关键角色，其作用是文化引领和工作指导。
    - 向新员工提出期望：主动与导师沟通，积极请教。
- **互动引导**：可问：“大家已经知道自己的导师是谁了吗？有没有提前沟通？”
- **讲师提示**：内部转岗政策是“鼓励”而非“随意”，需强调流程合规性。对导师制的期望要传递给学员，这也是对新员工的行为引导。

### 第24页：过渡页：顺利启航：入职实操与支持
- **页码标题**：24 - 过渡页（模块五）
- **建议时长**：0.5分钟
- **讲解要点**：
    - 明确模块五目标：清晰回顾入职流程，掌握关键支持资源。
    - 提出引导性问题：“入职第一天做什么？遇到困难找谁？”
- **互动引导**：无。
- **讲师提示**：进入最后一个实操模块，语气应务实、亲切。

### 第25页：报到当天关键步骤
- **页码标题**：25 - 报到当天关键步骤
- **建议时长**：8分钟
- **讲解要点**：
