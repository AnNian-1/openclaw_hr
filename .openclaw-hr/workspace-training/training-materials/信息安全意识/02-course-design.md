# 信息安全意识培训 · 课程设计

> AI 辅助生成，讲师审核后交付
> 最近更新：2026-08

## 一、课程总体结构

| 维度 | 说明 |
|------|------|
| 课程名称 | 信息安全意识——新员工必修课 |
| 培训对象 | 新入职员工（入职 1 周内） |
| 总时长 | 2 小时 15 分钟（含 10 分钟休息） |
| 教学方式 | 讲授 40% + 案例分析 25% + 互动演练 25% + 答疑 10% |
| 授课形式 | 线下集中（支持后续录制线上复习） |
| 讲师 | IT 支持部 / 法务与合规部 |

## 二、模块详细设计

### 模块 1：开场与安全意识唤醒（15 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 让学员认识到信息安全与自身密切相关，打破"安全是 IT 部门的事"的认知 |
| 内容点 | ① 破冰：你今天泄露了多少信息？（现场小测试）<br>② 真实案例：某 SaaS 公司因新员工误操作导致客户数据泄露事件<br>③ 星桥科技信息安全总体要求概述 |
| 教学方式 | 互动测试 + 案例讲授 |
| 对应目标 | T1 |

### 模块 2：公司信息安全政策与制度（25 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 掌握公司信息安全政策核心要求，理解保密义务和违规后果 |
| 内容点 | ① 信息安全政策框架与适用范围<br>② 数据分级分类标准（公开 / 内部 / 机密 / 绝密）<br>③ 《保密协议》核心条款解读<br>④ 违规行为与处罚措施（口头警告 → 解除劳动关系 → 法律追责）<br>⑤ 日常合规红线速查 |
| 教学方式 | 讲授 + 互动问答 |
| 对应目标 | T1, T4 |

### 模块 3：识别网络攻击（30 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 能识别钓鱼邮件、社会工程、恶意软件等常见攻击手段 |
| 内容点 | ① 钓鱼邮件识别：发件人地址、链接悬停、附件类型、紧急话术<br>② 社会工程攻击：冒充领导/客户/IT 的电话与消息<br>③ 恶意软件传播途径：U 盘、下载站、不明链接<br>④ 现场演练：真假邮件辨别（6 封邮件样本） |
| 教学方式 | 案例分析 + 互动演练 |
| 对应目标 | T2 |

### 模块 4：密码与账号安全（20 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 掌握密码管理规范，正确使用多因素认证 |
| 内容点 | ① 强密码标准：长度 ≥ 12 位、含大小写字母 + 数字 + 特殊字符<br>② 密码管理工具推荐（1Password / 公司密码管理器）<br>③ 多因素认证（MFA）设置演示<br>④ 常见密码攻击方式：暴力破解、撞库、键盘记录<br>⑤ 实操：为公司账号设置强密码并启用 MFA |
| 教学方式 | 讲授 + 实操演练 |
| 对应目标 | T3 |

### 模块 5：数据安全与办公规范（25 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 能按公司数据分级标准分类信息，正确处理和传输敏感数据 |
| 内容点 | ① 数据分级实操：日常工作中的信息属于哪个级别？<br>② 文件传输规范：内部文件用什么工具、禁止用什么渠道<br>③ 办公设备安全：锁屏习惯、公共 Wi-Fi 风险、USB 管理<br>④ 远程办公安全要求（VPN、企业微信、云盘使用规范）<br>⑤ 社交媒体安全：哪些内容不能发、拍照注意什么 |
| 教学方式 | 案例分析 + 分组练习 |
| 对应目标 | T4 |

### 模块 6：安全事件上报与应急响应（10 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 知道发现安全事件时该联系谁、提供什么信息、走什么流程 |
| 内容点 | ① 安全事件定义与常见类型（数据泄露、账号被盗、设备丢失、可疑邮件）<br>② 上报流程：第一时间联系 IT 支持部 → 填写事件报告 → 配合调查<br>③ 紧急联系方式与上报渠道<br>④ 情景模拟：收到可疑邮件后该怎么处理？ |
| 教学方式 | 讲授 + 情景模拟 |
| 对应目标 | T5 |

### 模块 7：总结与答疑（10 分钟）

| 维度 | 内容 |
|------|------|
| 目标 | 巩固核心知识点，解答学员疑问 |
| 内容点 | ① 核心要点回顾（一页速查卡）<br>② 课后行动清单发布<br>③ 现场答疑<br>④ 课后测试说明 |
| 教学方式 | 互动问答 |
| 对应目标 | T1–T5 综合 |
