# 《信息安全意识》课程设计方案

## 一、课程总体结构

本课程采用“线上直播/录播 + 线下工作坊/案例研讨”的混合式学习模式，总时长约为2.5小时。课程设计遵循“意识唤醒 -> 知识传授 -> 技能演练 -> 行为引导”的逻辑，旨在将信息安全的外部要求内化为员工的自觉行为。

- **核心形式**：以线上直播/录播为主，便于全员覆盖；针对关键岗位或新员工，辅以线下的互动工作坊。
- **课程产出**：学员完成学习并通过测试后，可获得信息安全意识培训证书，并计入个人学习记录。

## 二、模块详细设计

### 模块一：引言：安全是我们的共同责任
*   **时长**：15分钟
*   **目标**：建立培训基调，关联公司价值观，阐明信息安全与每位员工的切身关系。（对应目标：T1）
*   **内容点**：
    1.  欢迎与课程目标介绍。
    2.  从公司“客户第一”和“务实诚信”的价值观出发，强调保护客户数据与公司商业秘密是践行价值观的核心表现。
    3.  展示一个简短的模拟数据泄露案例，说明其对公司业务、客户信任及个人职业生涯的毁灭性影响。
*   **教学方式**：讲师讲解、案例视频、提问互动。

### 模块二：守护数据资产：从保密协议到日常操作
*   **时长**：40分钟
*   **目标**：使学员理解数据分类与保密要求，掌握安全处理信息的具体方法。（对应目标：T2, T3）
*   **内容点**：
    1.  **核心制度回顾**：解读《保密协议》的核心条款与法律效力，强调入职即承诺的严肃性。
    2.  **数据分类与场景**：介绍公司可能的信息分类（如公开、内部、机密），并对应到具体工作场景（如市场宣传材料为公开，产品路线图为内部，客户数据库为机密）。
    3.  **安全操作指南**：
        *   数据存储：使用公司授权的云盘/服务器，禁止使用个人网盘。
        *   数据传输：加密传输敏感文件，禁止通过公共邮箱、社交软件传输。
        *   数据销毁：废弃的纸质文件必须用碎纸机处理。
*   **教学方式**：讲师讲解、政策文档展示、小组讨论（提供场景卡片，判断处理方式对错）。

### 模块三：识破陷阱：防范社交工程与网络威胁
*   **时长**：35分钟
*   **目标**：提升学员对钓鱼邮件、诈骗电话等常见攻击手法的识别与防范能力。（对应目标：T2, T5）
*   **内容点**：
    1.  **钓鱼邮件识别**：拆解钓鱼邮件的特征（发件人地址、紧急语气、可疑链接/附件、索要敏感信息），进行实战演练。
    2.  **常见威胁类型**：简要介绍勒索软件、假冒IT支持电话等其他社会工程学手段。
    3.  **“四不”原则**：不轻信、不点击、不透露、不转账。
    4.  **报告流程**：明确发现可疑邮件或攻击时，应立即上报主管并转发至IT支持部（公司《职能中心》架构中IT支持部为负责部门）。
*   **教学方式**：案例分析、真假邮件对比展示、模拟钓鱼邮件判断练习。

### 模块四：安全办公：保护设备与网络
*   **时长**：30分钟
*   **目标**：规范员工在办公设备使用、密码管理及远程办公中的安全行为。（对应目标：T4）
*   **内容点**：
    1.  **设备安全**：离开工位必锁屏（Win+L / Ctrl+Command+Q），设置强密码（长度、复杂度、定期更换），及时更新系统与软件补丁。
    2.  **网络环境安全**：公司网络、家庭网络、公共Wi-Fi的风险差异；必须通过公司VPN访问内部资源。
    3.  **远程/混合办公安全**：强调在非公司网络下处理工作的风险，提供安全检查清单（如检查家庭路由器密码、避免在公共电脑登录账号）。
*   **教学方式**：操作演示（如设置锁屏）、清单讲解、场景问答。

### 模块五：总结与承诺：共建安全文化
*   **时长**：10分钟
*   **目标**：强化关键行为，引导学员做出安全承诺，并了解持续学习资源。（对应目标：T5）
*   **内容点**：
    1.  课程核心要点快速回顾。
    2.  引导学员签署《信息安全行为承诺书》（线上电子签名）。
    3.  公布信息安全事件/疑虑的报告渠道。
    4.  介绍公司在线学习平台上的相关进阶课程。
*   **教学方式**：讲师总结、电子承诺签署、资源指引。

## 四、教学方式分布

- **讲师讲授**：约40%，用于传递核心概念、政策与知识。
- **案例分析与讨论**：约30%，用于分析真实或模拟场景，促进深度思考。
- **互动练习与演练**：约20%，如判断钓鱼邮件、设置密码练习，强化技能。
- **视频与多媒体展示**：约10%，用于提升课程吸引力，呈现抽象风险。
