# 某某公司 · 公司文化培训 PPT 大纲

**说明**：本大纲基于《需求分析》与《课程设计》编制，严格遵循四大模块结构，页码与内容一一对应。建议总课时约240分钟（4小时），含课间休息。

---

| **页码** | **标题** | **类型** | **要点（3-6条具体bullet）** | **所属模块** | **建议时长** |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | 封面 | 模块标题页 | - 课程名称：某某公司文化融入工作坊<br>- 核心理念：知行合一，从认知到践行<br>- 讲师姓名/部门<br>- 培训日期 | 总体 | 1分钟 |
| **2** | 我们为什么在这里？ | 课程目标页 | - **目标一**：理解并认同公司使命、愿景与价值观。<br>- **目标二**：熟悉公司组织架构，掌握跨部门协作方法。<br>- **目标三**：清晰规划个人在“P/M双通道”下的发展路径。<br>- **目标四**：承诺将文化要求转化为具体行动。 | 总体 | 2分钟 |
| **3** | 今天的旅程 | 议程页 | - 破冰与导入（10分钟）<br>- **模块一**：文化根基与认同（60分钟）<br>- **模块二**：组织架构与协作（50分钟）<br>- **模块三**：职业发展与融入（60分钟）<br>- **模块四**：综合应用与承诺（50分钟）<br>- 总结与行动（20分钟） | 总体 | 2分钟 |
| **4** | 破冰活动 | 互动页 | - 活动名称：“一句话连接”<br>- 规则：与身边同事分享“你加入某某公司最期待的一点是什么？”<br>- 目的：快速建立连接，营造开放氛围。<br>- 时间：3分钟分享，2分钟全场随机邀请分享。 | 总体 | 5分钟 |
| **5** | 模块一：文化根基与认同 | 模块标题页 | - 核心问题：我们是谁？我们为何奋斗？<br>- 本模块目标：达成对文化核心的“记忆”与“理解”。<br>- 关键活动：讲授、价值观排序讨论、案例演练。 | 模块一 | 1分钟 |
| **6** | 我们的使命与愿景 | 内容页 | - **使命**：用技术连接人与服务，让价值创造更高效。（基于素材抽象）<br>- **愿景**：成为企业协同与数据服务领域的首选伙伴。（基于素材抽象）<br>- 使命愿景如何指引我们的日常工作。<br>- **思考点**：你的日常工作如何与公司使命产生连接？ | 模块一 | 5分钟 |
| **7** | 五大价值观（上） | 内容页 | - **客户第一**：一切工作的出发点与落脚点。<br>  - 案例场景：当项目进度与客户临时需求冲突时，如何选择？<br>- **务实诚信**：脚踏实地，言行一致。<br>  - 行为准则：数据说话，承诺必达。 | 模块一 | 8分钟 |
| **8** | 五大价值观（下） | 内容页 | - **持续学习**：适应变化的基石。<br>  - 公司支持：在线学习平台、考证补贴等资源。<br>- **协作共赢**：打破壁垒，成就彼此。<br>  - 核心：知识共享、主动补位。<br>- **拥抱变化**：在动态中寻找机遇。<br>  - 关键：对新流程、新工具保持开放与适应。 | 模块一 | 8分钟 |
| **9** | 小组讨论：价值观排序 | 案例讨论页 | - **任务**：小组内讨论，根据“某某公司现阶段最应强化”的标准，对五大价值观进行排序并说明理由。<br>- **输出**：小组排序结果及Top 1价值观的强化理由（3条）。<br>- **时间**：15分钟讨论，5分钟小组汇报。 | 模块一 | 20分钟 |
| **10** | 文化故事案例 | 案例讨论页 | - **案例呈现**：（基于素材抽象）销售部与产品部因一个客户需求优先级问题产生分歧，最终如何基于“客户第一”和“协作共赢”达成解决方案。<br>- **小组任务**：分析此案例中体现了哪些价值观？哪些行为是正面示范？<br>- **讲师点评**：连接价值观与具体行为。 | 模块一 | 18分钟 |
| **11** | 模块一 小结 | 过渡页 | - **回顾**：我们共同认知了公司的使命、愿景和五大价值观。<br>- **关键收获**：价值观不是口号，而是具体工作场景中的行为选择指南。<br>- **预告**：接下来，我们将了解实现这些价值的“舞台”——公司的组织架构。 | 模块一 | 2分钟 |
| **12** | 模块二：组织架构与协作 | 模块标题页 | - 核心问题：我在哪里？我如何与“舞台”上的其他人连接？<br>- 本模块目标：分析跨部门协作案例，识别文化要素与改进点。<br>- 关键活动：架构图讲解、互动游戏、案例分析。 | 模块二 | 1分钟 |
| **13** | 公司五大体系概览 | 内容页 | - **研发与技术中心**：产品实现与技术创新引擎。<br>- **产品中心**：用户需求与市场策略的连接器。<br>- **商业化中心**：市场拓展与客户价值实现前线。<br>- **职能支持体系**：包括HR、财务、法务等，提供运营保障。<br>- **战略与运营中心**：统筹协调与战略落地推手。<br>- **关系**：以“协同云”、“数据洞察”产品为纽带，形成价值创造闭环。 | 模块二 | 8分钟 |
| **14** | 跨部门协作流程 | 内容页 | - **典型协作场景**：新功能从想法到上线。<br>- **关键节点**：需求评审（产品/研发/商业）、开发与测试（研发）、上线推广（商业/产品）。<br>- **文化要求**：在每个节点主动沟通、信息透明、目标对齐（基于“协作共赢”）。<br>- **HR小慧的角色**：政策咨询、员工关怀入口。 | 模块二 | 7分钟 |
| **15** | 互动游戏：“部门连连看” | 互动游戏页 | - **目标**：加深对各部门职责与协作节点的理解。<br>- **形式**：给出10个常见工作任务（如“处理客户投诉”、“规划下季度产品路线图”），小组讨论其主导部门及需协作的部门。<br>- **评估**：讲师公布参考答案与协作逻辑。 | 模块二 | 15分钟 |
| **16** | 案例分析：跨部门项目复盘 | 案例讨论页 | - **案例背景**：（基于素材抽象）一个涉及产品、研发、销售的“数据洞察”定制项目延期交付的简化案例。<br>- **小组任务**：<br>  1. 分析案例中阻碍协作的环节。<br>  2. 运用公司价值观，提出3条可避免或改善此问题的具体建议。<br>- **汇报与讨论**：聚焦“协作共赢”与“务实诚信”的应用。 | 模块二 | 15分钟 |
| **17** | 模块二 小结 | 过渡页 | - **回顾**：我们熟悉了公司的组织“地图”和协作“路径”。<br>- **关键收获**：高效协作源于对彼此职责的尊重和对共同目标的坚持。<br>- **预告**：有了舞台，接下来如何规划自己的成长路径？ | 模块二 | 2分钟 |
| **18** | 模块三：职业发展与融入 | 模块标题页 | - 核心问题：我如何在这里成长？<br>- 本模块目标：应用双通道体系，规划个人发展路径。<br>- 关键活动：体系讲解、个人规划练习、Q&A。 | 模块三 | 1分钟 |
| **19** | 双通道（P/M）职级体系 | 内容页 | - **专业通道（P）**：深耕专业技能，成为领域专家。从P1到P8。<br>- **管理通道（M）**：承担团队与业务管理职责。从M1到M5。<br>- **核心理念**：两条通道平等受重视，鼓励员工基于兴趣和能力选择。<br>- **转换机制**：符合条件（如绩效、能力评估）可在通道间转换。 | 模块三 | 10分钟 |
| **20** | 晋升：条件与流程 | 内容页 | - **基本条件**：绩效达标、能力符合目标职级要求、价值观践行良好。<br>- **关键流程**：个人申请/主管提名 → 人才盘点/评审会 → 结果公示与反馈。<br>- **重要节点**：三方评估（个人、主管、HR/相关方）。<br>- **提示**：晋升不是唯一目标，持续成长才是。 | 模块三 | 10分钟 |
| **21** | 横向发展：内部转岗 | 内容页 | - **政策支持**：鼓励基于职业兴趣的内部流动。<br>- **申请条件**：在职时间、绩效、与目标岗位的匹配度评估。<br>- **流程**：与现主管及目标部门沟通 → 参加评估 → 成功后安排交接与融入。<br>- **案例**：从“商业化中心”转岗至“产品中心”的路径设想。 | 模块三 | 8分钟 |
| **22** | 你的发展支持系统 | 内容页 | - **导师制**：为你提供文化融入与专业指导的“引路人”。<br>- **人才盘点**：公司系统性识别高潜人才，匹配发展机会。<br>- **在线学习平台与考证补贴**：用于自我提升的资源。<br>- **如何利用**：主动与主管、HR（小慧）沟通你的发展诉求。 | 模块三 | 7分钟 |
| **23** | 个人练习：绘制我的发展路径 | 个人练习页 | - **工具**：提供P/M职级体系卡片。<br>- **任务**：思考并填写：<br>  1. 我当前所在的通道和大致阶段。<br>  2. 我未来1-2年希望达到的目标（P/M哪个序列的哪个层级）。<br>  3. 为实现这个目标，我最需要提升的1-2项能力或补充的经历是什么？<br>- **可选**：与邻座同事简要分享。 | 模块三 | 15分钟 |
| **24** | 模块三 Q&A | Q&A页 | - **目的**：解答关于职级、晋升、转岗、发展资源的具体疑问。<br>- **形式**：收集匿名问题卡片，讲师集中解答；或现场举手提问。<br>- **讲师准备**：需熟读《08-培训与晋升通道.md》文件，确保解答准确。 | 模块三 | 10分钟 |
| **25** | 模块三 小结 | 过渡页 | - **回顾**：我们梳理了清晰的职业发展双通道和具体资源。<br>- **关键收获**：主动规划，善用资源，是通往成长的钥匙。<br>- **预告**：最后，我们将把所有模块串联，在一个综合情景中演练。 | 模块三 | 2分钟 |
| **26** | 模块四：综合应用与承诺 | 模块标题页 | - 核心问题：当挑战来临时，我如何做？<br>- 本模块目标：综合运用文化、架构与制度知识，做出行为承诺。<br>- 关键活动：情景演练、总结回顾、承诺制定。 | 模块四 | 1分钟 |
| **27** | 综合情景演练 | 情景演练页 | - **情景**：你是一名“协同云”产品的运营人员（P3），发现一个重要客户对产品某功能有强烈不满，而该功能的优化需要产品部和研发部的支持，但他们当前排期很满。<br>- **任务**：<br>  1. 你会如何行动？运用哪些价值观？<br>  2. 你会如何跨部门沟通和推动？<br>  3. 这个过程如何体现你对个人成长（如“协作”能力）的追求？<br>- **演练形式**：小组讨论20分钟，代表陈述5分钟，讲师反馈5分钟。 | 模块四 | 30分钟 |
| **28** | 课程核心知识回顾 | 总结回顾页 | - **文化根基**：使命、愿景、五大价值观——我们的“灵魂”。<br>- **组织架构**：五大体系与协作流程——我们的“骨骼与脉络”。<br>- **发展通道**：P/M双通道与晋升、转岗——我们的“成长阶梯”。<br>- **综合应用**：价值观指导下的行为决策——我们的“肌肉记忆”。 | 模块四 | 5分钟 |
| **29** | 制定我的文化践行承诺 | 个人反思页 | - **任务**：结合今天所学与自身岗位，制定1-2条具体、可行动的文化践行承诺。<br>- **提示**：承诺应具体（What）、可行（How），并与价值观关联（Why）。<br>- **示例**：“我承诺，在接下来的项目中，主动邀请协作方参与需求评审会，践行‘协作共赢’。”<br>- **时间**：5分钟书写，可选自愿分享。 | 模块四 | 10分钟 |
| **30** | 行动号召与领导寄语 | 结束页 | - **讲师总结**：文化的生命力在于每个人的日常行动。<br>- **领导寄语（可选）**：邀请一位管理者分享对学员践行文化的期待。<br>- **行动号召**：从明天起，选择一个承诺开始践行，并影响身边的同事。 | 模块四 | 4分钟 |
| **31** | 课程评估与答疑 | 评估页 | - **发放并回收**：课程效果评估问卷。<br>- **开放答疑**：回答任何遗留问题。<br>- **后续指引**：告知后续行动（如学习资料、社群、导师对接等）。 | 总体 | 10分钟 |
