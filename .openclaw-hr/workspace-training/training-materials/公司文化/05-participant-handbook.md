# 某某公司文化融入工作坊 · 学员手册

欢迎加入某某公司！本手册是你培训过程中的随身指南，旨在帮你快速理解公司核心，明确发展方向，并找到行动的起点。请跟随课程节奏，在相应模块处做笔记、完成练习。

## 课程目标
通过本次工作坊，你将：
1.  理解并认同公司使命、愿景与价值观。
2.  熟悉公司组织架构，掌握跨部门协作方法。
3.  清晰规划个人在“P/M双通道”下的发展路径。
4.  承诺将文化要求转化为具体行动。

## 模块一：文化根基与认同
*核心问题：我们是谁？我们为何奋斗？*

### 1.1 我们的使命与愿景
- **使命**：用技术连接人与服务，让价值创造更高效。
- **愿景**：成为企业协同与数据服务领域的首选伙伴。
- **你的连接点**：思考你的日常工作如何与公司使命产生连接？（例如：你处理的客户问题、你参与的项目，如何体现了“连接”与“价值创造”？）

### 1.2 五大核心价值观
价值观是我们做决策和判断时的根本依据。

| 价值观 | 含义与行为指引 | 你在工作中的提示 |
| :--- | :--- | :--- |
| **客户第一** | 一切工作的出发点与落脚点。 | 当多项任务冲突时，优先考虑哪项对客户价值最大？ |
| **务实诚信** | 脚踏实地，言行一致。用数据说话，对承诺负责。 | 汇报工作时，确保信息准确；对同事的承诺，务必兑现。 |
| **持续学习** | 主动适应变化，保持成长。 | 积极利用公司学习资源，将新知识应用于实践。 |
| **协作共赢** | 打破部门墙，知识共享，主动补位，成就彼此。 | 在跨部门会议前，提前分享资料；同事求助时，在能力范围内积极响应。 |
| **拥抱变化** | 对新流程、新工具保持开放与适应，在动态中寻找机遇。 | 当团队推行新工具时，主动学习并提供建设性反馈。 |

### 1.3 文化如何落地
- **价值观排序**：小组讨论中，思考现阶段公司最应强化的价值观是什么？为什么？
- **案例分析**：在“销售与产品部因客户需求产生分歧”的案例中，观察价值观如何具体指导行为选择。

**【本模块速查】**
- **Q：五大价值观如何快速记住？**
  A：记住关键词：“客务学协变”（客户第一、务实诚信、持续学习、协作共赢、拥抱变化）。核心是：以客户为中心，脚踏实地干，持续学新知，一起赢未来。
- **Q：在工作中，如果不同价值观似乎有冲突怎么办？（例如：客户紧急需求 vs 团队既定计划）**
  A：首先，回归“客户第一”原则，评估需求的真实性与紧迫性。其次，基于“协作共赢”和“务实诚信”，与相关方坦诚沟通，寻找对客户和公司整体最优的解决方案，而不是简单取舍。

## 模块二：组织架构与协作
*核心问题：我在哪里？我如何与“舞台”上的其他人连接？*

### 2.1 公司五大体系概览
我们的组织围绕核心产品“协同云”和“数据洞察”运转，形成价值创造闭环。
- **研发与技术中心**：产品实现与技术创新引擎。
- **产品中心**：用户需求与市场策略的连接器。
- **商业化中心**：市场拓展与客户价值实现前线。
- **职能支持体系**：HR、财务、法务等，提供运营保障。
- **战略与运营中心**：统筹协调与战略落地推手。

**图示理解**：想象一个环形，所有中心围绕“客户价值”协同工作。

### 2.2 跨部门协作流程
一个典型的功能迭代流程：
1.  **需求评审**：产品、研发、商业化共同参与。
2.  **开发与测试**：研发主导。
3.  **上线与推广**：商业化与产品协同。
- **文化要求**：在每个节点，**主动沟通、信息透明、目标对齐**是高效协作的关键。
- **你的支持伙伴**：有任何人事政策、福利或职业困惑，都可以咨询HR小慧。

### 2.3 互动游戏：“部门连连看”
试着思考以下常见任务，主要由哪个部门主导，需要哪些部门协作？
- 处理客户投诉
- 规划下季度产品路线图
- （在培训中还有更多任务，与小组一起完成）

**【本模块速查】**
- **Q：如果不清楚某件事该找哪个部门，怎么办？**
  A：第一步，询问你的直属主管。第二步，参考公司内部通讯录或协作平台查找对应接口人。第三步，可以咨询HR小慧，她会帮你指引。
- **Q：推动一个跨部门项目，感觉阻力很大，从哪里入手？**
  A：运用“协作共赢”价值观。1. **对齐目标**：重申项目对各方及公司的共同价值。2. **透明信息**：确保各方掌握相同信息，减少误解。3. **寻求支持**：主动与对方部门的负责人或关键接口人进行一对一沟通，理解其挑战并共同寻找解决方案。

## 模块三：职业发展与融入
*核心问题：我如何在这里成长？*

### 3.1 双通道（P/M）职级体系
公司为你提供两条平等的晋升路径：
- **专业通道（P序列）**：深耕专业技能，成为领域专家（P1-P8）。
- **管理通道（M序列）**：承担团队与业务管理职责（M1-M5）。
- **核心**：鼓励你基于兴趣和能力选择，并可在符合条件时转换通道。

### 3.2 晋升：条件与流程
- **基本条件**：绩效达标、能力符合目标职级要求、价值观践行良好。
- **关键流程**：个人申请/主管提名 → 人才盘点/评审会 → 结果公示与反馈。
- **关键提示**：晋升是成长的结果之一，持续提升能力和贡献才是根本。

### 3.3 横向发展：内部转岗
- **政策支持**：鼓励基于职业兴趣的内部流动。
- **申请条件**：通常需要满足在职时间、绩效要求，并通过与目标岗位的匹配度评估。
- **流程**：与现主管及目标部门沟通 → 参加评估 → 成功后安排交接与融入。

### 3.4 你的发展支持系统
- **导师**：为你提供文化融入与专业指导的“引路人”。
- **人才盘点**：公司系统性识别高潜人才，匹配发展机会。
- **在线学习平台与考证补贴**：你自我提升的免费资源。
- **行动关键**：**主动沟通**你的发展诉求，与主管、HR小慧保持交流。

### 3.5 个人练习：绘制我的发展路径
请思考并简要填写：
1.  我当前所在的通道和大致阶段：（例：技术类，P2）
2.  我未来1-2年希望达到的目标：（例：产品类，P3）
3.  为实现这个目标，我最需要提升的1-2项能力或补充的经历是：（例：用户调研能力、参与一个完整的产品上线项目）

**【本模块速查】**
- **Q：P序列和M序列哪个更好？**
  A：没有绝对好坏，只有适合与否。P序列追求专业深度，M序列侧重管理广度。公司同等重视。建议根据你的兴趣、优势和长期职业设想来选择。
- **Q：晋升大概需要多久？有固定时间表吗？**
  A：没有固定时间表。晋升取决于个人成长速度、业务需要和机会。核心是持续展现高绩效和更高的能力水平。定期与你的主管进行发展对话，了解差距和计划。
- **Q：对另一个岗位很感兴趣，如何启动转岗？**
  A：首先，确保你当前岗位工作稳定，绩效良好。其次，非正式地与目标部门的同事或负责人了解岗位要求。最后，正式与你的现主管和HR小慧沟通你的想法，获取他们的建议和支持，再启动正式流程。

## 模块四：综合应用与承诺
*核心问题：当挑战来临时，我如何做？*

### 4.1 综合情景演练
**情景**：你是一名“协同云”产品的运营人员（P3），发现一个重要客户对产品某功能强烈不满，而该功能的优化需要产品部和研发部支持，但他们当前排期很满。
- **你的行动思考**：
  1.  你会采取哪些具体行动？（第一步做什么？）
  2.  在沟通中，你会如何运用公司价值观？（尤其是哪几条？）
  3.  这个过程如何帮助你提升“协作”或“问题解决”等能力？

### 4.2 课程核心知识回顾
- **灵魂**：使命、愿景、五大价值观。
- **骨骼与脉络**：五大体系与协作流程。
- **成长阶梯**：P/M双通道、晋升与转岗机制。
- **肌肉记忆**：在挑战中综合运用以上知识，做出正确行为。

### 4.3 制定我的文化践行承诺
请结合今天所学与你的岗位，制定1-2条具体、可行动的承诺。
- **示例**：“我承诺，在接下来的第一个项目需求会上，主动介绍自己，并邀请一位跨部门同事交换对需求的看法，以践行‘协作共赢’。”
- **我的承诺**：
  1.  _________________________（做什么？）
  2.  _________________________（如何做？与哪个价值观关联？）
