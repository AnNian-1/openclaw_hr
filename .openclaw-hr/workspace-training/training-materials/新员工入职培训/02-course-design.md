# 新员工入职培训 - 课程设计

## 一、课程总体结构
本课程设计遵循新员工入职的自然时序，从“欢迎与融入”开始，逐步深入到“文化制度”、“工具系统”、“发展路径”，最终以“结业与启程”收尾。课程采用混合式学习模式，结合集中讲授、互动问答、线上自学和实操演练，确保新员工在轻松、清晰的氛围中完成角色转变。

## 二、模块详细设计

### 模块一：欢迎加入星桥（时长：30分钟）
- **目标**：营造欢迎氛围，建立初步连接；让学员了解培训整体安排。
- **内容点**：
    1.  讲师自我介绍与培训目标概述。
    2.  引导新员工进行简短的破冰自我介绍（姓名、岗位、入职前的一个有趣事实）。
    3.  概述本次入职培训的日程、目标及后续跟进步骤（参考《09-入职流程》四）。
- **教学方式**：引导式讨论、快速问答。

### 模块二：公司概览与文化融入（时长：60分钟）
- **目标**：使学员理解公司全貌与核心文化，产生认同感。（对应目标T1、T5）
- **内容点**：
    1.  **公司简介**：公司成立时间、业务定位（企业级SaaS与数据智能）、两条主营产品线、服务客户规模、发展阶段。（基于《00-公司简介与组织架构》一）
    2.  **使命愿景价值观**：详细解读“用数据智能让企业管理更高效”的使命及五大价值观，并引导讨论如何在工作中践行。（基于《00》一）
    3.  **组织架构**：以架构图为引导，讲解五大中心（研发、产品、商业化、职能、战略与运营）的核心职能，让学员定位自身所属体系。（基于《00》二）
    4.  **办公地点与工作制度**：介绍三个办公地点及其主要团队，简要说明工作时间、办公模式与企业IM。（基于《00》四、五）
- **教学方式**：讲授、图文展示、互动问答（“你认为哪个价值观对你当前工作最重要？”）。

### 模块三：入职实务与支持系统（时长：75分钟）
- **目标**：确保学员掌握入职关键手续、支持渠道与合规要点。（对应目标T2）
- **内容点**：
    1.  **入职手续精讲**：回顾报到当天已签署的关键文件（劳动合同、保密协议等），强调其法律意义与员工权责。（基于《09》三.1）
    2.  **HR支持体系**：详细介绍人力资源部四大模块（招聘、人事薪酬、组织发展培训、员工关系）的职责，明确各类事务的对接窗口。重点介绍HR数字员工“小慧”的功能与使用场景。（基于《00》三）
    3.  **IT与行政支持**：说明办公设备领取、账号权限申请、门禁卡等事务的办理渠道（IT支持部、行政部）。（基于《09》三.2）
    4.  **合规警示**：重申公司不得扣押证件、不得收取押金等法律底线，增强新员工的法律保护意识。（基于《09》二.1）
- **教学方式**：流程图讲解、案例模拟（“如果你的电脑无法连接网络，第一步应该做什么？”）、平台演示（企业微信中查找“小慧”）。

### 模块四：职业发展与培训体系（时长：45分钟）
- **目标**：让学员清晰了解在公司的成长路径与学习资源，规划早期发展。（对应目标T3、T4）
- **内容点**：
    1.  **双通道职级体系**：讲解专业通道（P）与管理通道（M）的职级对应关系、发展逻辑及转换机制，强调专业深度同样可以实现职业晋升。（基于《08》二）
    2.  **晋升与考核机制**：说明晋升周期（每年2次）、基本条件（司龄、绩效、能力），以及试用期转正考核的流程与时间点（试用期满前两周发起）。（基于《08》三、《09》六）
    3.  **公司培训资源**：介绍公司提供的四类培训（入职、通用、专业、管理者），以及在线学习平台、外部培训与考证补贴政策。（基于《08》一）
    4.  **导师制**：说明导师的角色、职责（3个月内提供业务指导与文化融入支持），以及如何与导师有效互动。（基于《08》五）
- **教学方式**：结构化讲授、图表对比（P/M通道）、经验分享（可邀请一位资深导师或近期转正员工录制短视频）。

### 模块五：结业与启程（时长：15分钟）
- **目标**：总结培训要点，明确后续步骤，颁发结业证明。
- **内容点**：
    1.  快速回顾本次培训的五大核心模块与关键信息。
    2.  明确告知学员：入职首月由部门安排岗位培训；遇到任何问题，可随时使用“小慧”或联系导师、HR。
    3.  进行简短的结业测评（5-10道选择题，覆盖T1-T5核心知识点）。
    4.  线上颁发电子结业证书，并合影留念。
- **教学方式**：总结演讲、即时测评、仪式性活动。

## 四、教学方式分布
- **讲授与演示**：40%（用于传递核心概念、流程与政策）。
- **互动与讨论**：30%（用于深化理解、连接经验，如价值观讨论、案例模拟）。
- **实操与自学**：20%（如平台操作演示、观看短视频、完成自学任务）。
- **评估与仪式**：10%（如结业测评、颁发证书）。
