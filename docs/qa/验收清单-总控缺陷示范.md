### D-002 · P3 · exec 闸 socket（不是入职 Lobster 门）

这是 Gateway 拦 Agent **`exec` 命令**的配置，不是合同/账号 `resume yes|no`。本机 allowlist 主要约束 **recruitment** / **er-admin**。

**真源：** `~/.openclaw/exec-approvals.json`（Gateway 认这份）。  
**副本：** 项目 `.openclaw-hr/exec-approvals.json`（另一条 sock，不要当 live）。  
参考 yaml / README 里的 `/root/.openclaw-hr/...` 不是审批真源。2026-08-26 曾见项目文件指 `/root`；2026-08-27 live 已是 `$HOME/.openclaw/exec-approvals.sock`。

| | |
|--|--|
| 动作 | 读 **`~/.openclaw/exec-approvals.json`** 的 `socket.path`，对比 `$HOME`；不要只读项目内那份。`openclaw.yaml` 搜 approvals |
