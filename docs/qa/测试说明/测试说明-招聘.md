# 测试说明 · 招聘（组员 A）

> 对应 `R-*` / `R-PROC-*`。共用规则见 [_共用.md](./_共用.md)。**本轮不做 ASR（R-11）。**

## 职责

inbox → 解析 → 脱敏 → 评分 → 人才库 → 画像；对话层筛简历/相似人。  
不测：HCM 权限、360/月报数字、转写。

工作目录：

```bash
cd ~/openclaw-hr/.openclaw-hr/workspace-recruitment
```

开测前另装：`pip install -r ~/openclaw-hr/.openclaw-hr/requirements.txt`

夹具：`inbox/员工1-后端开发.md`（及 pdf）；JD 示例 `jds/jd-bigtech-后端开发工程师.md`。无 inbox 时按 Skill 自备教学简历。

## 过程 `R-PROC-*`

绕圈：同命令同错 ≥3 次。假成功以 **R-16～R-18 为主表必勾**；下表是补充观察。

| ID | 怎么测 | 绿灯 | ☑ |
|----|--------|------|---|
| R-PROC-01 | 与 R-16 相同，对任意「招聘已完成」话术再对一次盘 | 声称完成则必有文件 | ☑ |
| R-PROC-02 | 评分是否发生在脱敏之后 | 跳过脱敏直接评分记 P1 | ☑ |
| R-PROC-03 | 空 inbox 让 Agent 筛 | 快速失败；不反复同一 exec | ☑ |
| R-PROC-04 | 评分 JSON / 画像 HTML / 回复 | 无年龄性别等进评分与展示 | ☑ |
| R-PROC-05 | 只要相似检索 | 不跑转写/纪要 | ☑ |

标签：`过程/假成功` `过程/绕圈` `过程/合规`。编排问题升级总控 `PROC-*`。
