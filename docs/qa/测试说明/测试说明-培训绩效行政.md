# 测试说明 · 培训 + 绩效 + 行政（组员 C）

> 对应 `X-*` / `X-PROC-*`。共用规则见 [_共用.md](./_共用.md)。

## 职责

培训物料 + 自检；360 聚合/看板；政策问答；月报 eval。  
不测：inbox 全链路、HCM 五部门深测。

```bash
pip install -r ~/openclaw-hr/.openclaw-hr/requirements.txt   # pandas 等；HCM 那份不够
```

工作区：`workspace-training/` · `workspace-performance/` · `workspace-er-admin/`。

**政策问答（X-08 / X-18）** 依赖腾讯 IMA 三件套（见 `answering-hr-policy-questions/SKILL.md`）：

| 变量 | 用途 |
|------|------|
| `IMA_OPENAPI_CLIENTID` / `IMA_OPENAPI_APIKEY` | OpenAPI 鉴权 |
| **`IMA_HR_KNOWLEDGE_BASE_ID`** | **必须**指向已上传 00–13 政策的「HR政策知识库」 |

**开测前自检（否则 X-08 不能判「编造」）：**

```bash
source ~/openclaw-hr/.openclaw-hr/env.sh
cd ~/openclaw-hr/.openclaw-hr/workspace-er-admin
node skills/answering-hr-policy-questions/scripts/search_ima_policies.cjs --list-kb
# 确认列表中有「HR政策知识库」且 content_count > 0；把其 id 写入 env.sh 的 IMA_HR_KNOWLEDGE_BASE_ID
node skills/answering-hr-policy-questions/scripts/search_ima_policies.cjs "年假到年底没休完怎么办"
# 期望 ok:true、hit_count>0；hits 含《03-假期政策》与 §2.3 片段（如「6 月 30 日」「300%」）
```

- **仅有 CLIENTID/APIKEY、未配 KB ID**：脚本可能报「知识库为空」——这是**环境未就绪**，不是「IMA 无政策」。此时 Agent 应明确检索失败；若仍给具体制度数字，记合规问题，但**先修 env**。
- **无凭证**：允许明确「无法检索知识库」；**禁止**用模型常识冒充公司制度。
- **有凭证且检索成功**：必须按 `highlight` 原文回答并引用出处（如《03-假期政策》§2.3）；数字与 highlight **一致**算通过。

er-admin 在配置里 **deny 写文件**，只允许 `exec`+`read`。让它改 md 很容易绕圈（X-PROC-03）。
