## D-008

标题：[入职/对话] router 首次对话不路由 onboarding，需明确话术  
级别：P3  
Agent / Skill：router → onboarding

发生了什么：首次 `openclaw agent --agent router -m "请查询测试员入职进度"`，router 返回「全新工作区，没有任何上下文信息」，未路由到 onboarding。加话术「路由到入职子Agent」后成功点名 `onboarding`。  
期望：router 能主动识别「查询入职进度」意图并路由到 onboarding，无需显式指令。或文档说明需要显式「路由到 XX 子Agent」的触发词。  
复现：
1. `source env.sh`
2. `openclaw agent --agent router -m "请查询测试员入职进度"`
3. 观察：router 返回「全新工作区无上下文」，未点名 onboarding

证据：首次对话完整回复「你好！我刚刚上线，这是一个全新的工作区，我还没有任何关于"测试员"或入职进度的上下文信息...」。第二次加「路由到入职子Agent」后回复「应该路由到 onboarding 这个 agent id」。  
是否稳定：首次失败，重试加话术后通过（偶发/模型抖动类）
