## 1. 这是什么、不是什么

「小慧」是一套 **OpenClaw 2026.5.12** 多 Agent HR 系统：招聘、入职、培训、绩效、行政。HCM（Vue + FastAPI）是**独立应用**，不是 Agent；入职小慧只 **GET** 花名册，不向 HCM 写入。

- **WebChat** → `router` → `sessions_spawn` 到五域。Router 不答 HR 业务。
- **飞书**（群 @ / 私聊）→ 直达 `er-admin`，**不经过** router。
- **Cron** → 入职 review 用 `onboarding`；月末月报用 **`er-admin-cron`**（与 `er-admin` 共用 `workspace-er-admin`）。飞书对话禁止出月报。

仓库根目录任意（本机曾用 `/home/yhwz/openclaw-hr`）。Profile 固定在 `<仓库>/.openclaw-hr/`。远程 https://github.com/yhwz131/openclaw 。数据为教学/演示与测试夹具，**禁止当真实人事、禁止编造花名册或绩效 S/A/B/C**。

## 2. 系统位置

```
 飞书 ──────────────────────────► er-admin
                                      │ ima-search（政策）
 WebChat ──► router ──sessions_spawn──┼── recruitment
                 │                    ├── onboarding ──GET── HCM :8000 / :5173
                 │                    ├── training
                 │                    ├── performance
                 │                    └── er-admin
 Cron ──► onboarding（真实入职 complete 后才挂 7/30/60/90）
 宿主机 crontab ──► maybe-monthly-report.sh ──► Canvas :18999
 Gateway :18790（飞书 / Lobster 都在此进程里；月报不经 Gateway）
```

- 子 Agent **互不** `sessions_spawn`。`hr-agents.yaml` 里的 `agent_to_agent` 只是拓扑说明。
- `maxChildrenPerAgent` / `runTimeoutSeconds`（8 / 1800）只写在 `agents.defaults.subagents`，不要写进 `agents.list[].subagents`。
- Canvas id 必须纯 ASCII（如 `hr-monthly-report`、`onboarding-dashboard`）。
- 另有 `main` Agent，不作业务入口。

各域介绍：`workspace-router/总控小慧INTRO.md`、`招聘小慧INTRO.md`、`Onboarding小慧INTRO.md`、`培训小慧INTRO.md`、`绩效小慧INTRO.md`、`er-admin小惠INTRO.md`。

## 3. 能力边界

| Agent | 做 | 明确不做 |
|-------|----|----------|
| router | 判域、`sessions_spawn`、转述 | 自己答政策/评分；暴露内部结构 |
| recruitment | 收信/解析/核对/脱敏/评分/画像/人才库/纪要 | 录用决定；发明人才库名单；本机 ASR 尚未补测前假装转写通过 |
| onboarding | Lobster 入职编排、30/60/90 review、看板 | 代批审批门；在 HCM 里悄悄建人；无拼音处理重名 |
| training | 按用户**点名**的物料生成 | 未点名就出全套 8 份；组织现场培训 |
| performance | 360 聚合与看板 | 缺自评仍出聚合；把夹具看板当校准会结果 |
| er-admin | 飞书政策问答（IMA） | 飞书出月报；用模型常识填政策；政策原文另存知识库 |
| er-admin-cron | 保留 Agent 定义，生产月报不再经它 | 飞书会话 |

HiTL：入职审批门、简历淘汰、绩效定级、政策红线（个人数据/争议/法律/无依据/需审批）必须人。halt≥3 天只**催办**，不自动 resume。

业务 Skill 以各 `workspace-*/skills/` 为准。招聘含收信共 13 个；行政另有 `ima-skill`。课程口中的「21 个 Skill / 6 个 Agent」已过时。

## 4. 怎么跑

以下用 `$REPO` 表示仓库根（clone 下来的 `openclaw-hr` 目录），`$PROFILE="$REPO/.openclaw-hr"`。

### 4.1 依赖

- OpenClaw **2026.5.12**（`openclaw --version`）。Lobster 插件必须同版本，不要装更新的 lobster。
- Node **≥ 22.16**（业务脚本 source `$PROFILE/scripts/prepend-node22.sh`）。
- conda 环境 **`openclaw-hr`** 与独立 **`funasr_me`**、各 Agent 用到的包和密钥：**[环境配置.md](环境配置.md)**。RAR 还要 rarlab **`unrar`**：`$PROFILE/scripts/ensure-rar-tools.sh`。
- `setup.sh` 只改写 `/Users/hsail/.openclaw-hr` 与 `/root/.openclaw-hr`。从本机 WSL 迁走时，还要把 `/home/yhwz/openclaw-hr` 自行替换成新路径。

### 4.2 密钥（只写变量名）

```bash
cp "$PROFILE/env.sh.example" "$PROFILE/env.sh"   # 不要提交 env.sh
```

yaml 用 env 引用，至少需要：

| 变量 | 用途 |
|------|------|
| `OPENCLAW_STATE_DIR` | 指到 `$PROFILE` |
| `OPENCLAW_GATEWAY_TOKEN` | Gateway；**不要**写入 `nginx/conf/canvas-proxy.conf`（由 `start-canvas-proxy.sh` 注入）。历史曾入库明文，迁云前轮换 |
| `XIAOMI_API_KEY` | Gateway 主模型 `xiaomi/mimo-v2.5-pro` |
| `SILICONFLOW_API_KEY` | 人才库 embedding、memorySearch |
| `DEEPSEEK_API_KEY` | 部分招聘脚本仍调 DeepSeek，不是 Gateway 默认对话模型 |
| `DASHSCOPE_API_KEY` | 部分脚本 / 旧 fallback |
| `FEISHU_APP_SECRET` | 飞书（appId 在 yaml） |
| IMA 相关（`IMA_OPENAPI_*`、`IMA_HR_KNOWLEDGE_BASE_ID`） | 政策检索 |

`source "$PROFILE/env.sh"` 后再起进程。

### 4.3 端口

| 端口 | 用途 | 注意 |
|------|------|------|
| 18790 | Gateway | 飞书/Cron/Lobster 随此进程 |
| 18791 | 乐奇眼镜上传 | 独立进程 `rokid-app-ingest`；Bearer 用 `ROKID_APP_INGEST_SECRET` |
| 18999 | Canvas 反代 | 只听 `127.0.0.1`，不对公网 |
| 8000 | HCM API | 云上建议绑 localhost；`hcm/start.sh` 目前 `--host 0.0.0.0` |
| 5173 | HCM 前端 | |

```bash
source "$PROFILE/env.sh"
openclaw gateway run                          # 终端保持
curl -sS http://127.0.0.1:18790/health
bash "$PROFILE/hcm/start.sh"                  # 或按 hcm/README
bash "$PROFILE/nginx/start-canvas-proxy.sh"   # 需 Gateway 已起
# bash "$PROFILE/scripts/rokid-app-ingest.sh" start   # 可选：乐奇眼镜 :18791
```

HCM 细节：[hcm/README.md](../.openclaw-hr/hcm/README.md)。组员逐步命令：[deployment-guide.md](deployment-guide.md)。

未请总控不要擅自在本机拉起这些服务（过夜曾要求停掉）。

### 4.4 对话入口

```bash
# WebChat / CLI：走 router
openclaw agent --agent router -m "从人才库里找几个和员工1背景相似的候选人"
openclaw agent --agent router -m "员工问年假到年底没休完怎么办？"

# 月报：不要对飞书或 router 说「出月报」。宿主机日检或运维 CLI：
# /opt/hr-ops/maybe-monthly-report.sh
bash "$PROFILE/workspace-er-admin/scripts/er-admin-run.sh" monthly-report --force 2026-07
```

飞书员工只问政策，命中 `er-admin`。
