# 三节点职责与工作流程

主 / 备 / 测试是三套独立机器上的 OpenClaw HR，不是同一 Gateway 里的三个 Agent。分册：

| 节点 | 一句话 | 文档 |
|------|--------|------|
| 主 | 复跑并沉淀；审过再推备 | [nodes/主节点.md](nodes/主节点.md) |
| 备 | 只收审过的记忆包 | [nodes/备节点.md](nodes/备节点.md) |
| 测试 | 验证流程；只合 git，不拷 memory | [nodes/测试节点.md](nodes/测试节点.md) |

## 开做梦的顺序（已定）

做梦仍关。打开前必须：其它内容落地 → **备节点第一次全量复制**（此时主节点做梦必须关）→ 再开主节点 dreaming。`frequency` 开的时候再填。
