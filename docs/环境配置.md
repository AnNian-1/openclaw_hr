# 环境配置（按 Agent / 运行时）

包不是「每个 Agent 一个 conda」。业务脚本共用 **`openclaw-hr`**，面试转写单独 **`funasr_me`**（numpy 大版本冲突，不能合并）。密钥只在 gitignore 的 `env.sh`。Gateway `exec` 里**禁止** `pip install`。

机器级步骤（Node、clone、启动）见 [deployment-guide.md](deployment-guide.md)。架构见 [项目说明.md](项目说明.md)。

`$PROFILE` = 仓库下 `.openclaw-hr/`。先 `source "$PROFILE/env.sh"`。

---

## 1. 三层运行时

| 层 | 是什么 | 清单 / 入口 |
|----|--------|-------------|
| OpenClaw | Gateway 2026.5.12 + Lobster 同版本 | `openclaw --version` |
| Node ≥ 22.16 | 招聘校验 JS、IMA 检索 `.cjs`、HCM 前端 | `scripts/prepend-node22.sh` |
| conda `openclaw-hr` | 几乎所有 Python Skill | [`conda/environment-openclaw-hr.yml`](../.openclaw-hr/conda/environment-openclaw-hr.yml) 与 [`requirements.txt`](../.openclaw-hr/requirements.txt)（内容应对齐） |
| conda `funasr_me` | **仅** `transcribing-interviews` | [`conda/environment-funasr-me.yml`](../.openclaw-hr/conda/environment-funasr-me.yml) |
| 系统 `unrar` | RAR 解压（python `rarfile` 不够） | `scripts/ensure-rar-tools.sh` 装进 `openclaw-hr` 的 `bin/` |
| HCM | FastAPI + Vue | `hcm/backend/requirements.txt` + `hcm/frontend` 的 npm |

装通用 Python：

```bash
conda env update -f "$PROFILE/conda/environment-openclaw-hr.yml"
conda activate openclaw-hr
bash "$PROFILE/scripts/ensure-rar-tools.sh"
# 若环境已存在、只补包：pip install -r "$PROFILE/requirements.txt"
```

壳脚本会 `source scripts/prepend-conda-python.sh`，把该 env 的 `python3` 放到 PATH 最前，避免落到 `/usr/bin/python3`（没 pandas）。

转写（换机补测时）：

```bash
conda env update -f "$PROFILE/conda/environment-funasr-me.yml"
# 可选：export FUNASR_VENV="$HOME/miniconda3/envs/funasr_me"
```

office-to-md 的 Node 依赖：

```bash
cd "$PROFILE/workspace-recruitment/skills/office-to-md-v2/office-to-md" && npm install
```

## 2. 按 Agent：Python/Node 包

router 无业务脚本，不额外装包。

| Agent | 用 `openclaw-hr` 里哪些包 | 另需 |
|-------|---------------------------|------|
| recruitment | `imap-tools`、`pdfminer.six`、`python-docx`、`python-pptx`、`rarfile`、`matplotlib`、`numpy` | Node 22（`validate_*.js` / `audit_*.js` / `score_*.js`）；`unrar`；office-to-md 的 npm；转写才用 `funasr_me` |
| onboarding | 标准库 + HTTP 调 HCM（无重 Python 科学栈） | Node 22（Lobster / 若干 sh）；HCM 进程 |
| training | 物料生成以 LLM + 本地 md 为主 | Node 若自检脚本需要则同 22 |
| performance | `python-docx`、`pypinyin`、`rarfile`、`matplotlib` | `unrar`（.rar 反馈包） |
| er-admin / er-admin-cron | `pandas`、`matplotlib`（月报） | Node 22（`ima-search` 的 `.cjs`） |
| HCM（非 Agent） | `fastapi`、`uvicorn`、`sqlalchemy`、`pydantic`、`python-multipart`、`websockets` | 前端 `npm install` |

360 的 `skills/aggregating-360-feedback/requirements.txt` 只有 `python-docx` 与 `pypinyin`，应已包含在 `openclaw-hr` 中，不要在 exec 里再 pip。

月报 SKILL 里若还写 conda `py312`，以 **`openclaw-hr` + prepend-conda-python** 为准。

## 3. 按 Agent：环境变量（只写名字）

全员先有：`OPENCLAW_STATE_DIR`、`OPENCLAW_GATEWAY_TOKEN`、`XIAOMI_API_KEY`。

| Agent / 能力 | 变量 |
|--------------|------|
| Gateway / Canvas | `OPENCLAW_GATEWAY_TOKEN`（由 `start-canvas-proxy.sh` 注入 nginx，不要提交进 conf） |
| 飞书 | `FEISHU_APP_SECRET`（appId 在 yaml） |
| 政策 IMA（er-admin） | `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`、`IMA_HR_KNOWLEDGE_BASE_ID` |
| 人才库 embedding、memorySearch | `SILICONFLOW_API_KEY`（ingest 默认模型 `BAAI/bge-large-zh-v1.5`，可用 `EMBEDDING_MODEL` 覆盖） |
| 招聘部分脚本回退 | `DEEPSEEK_API_KEY`、`DASHSCOPE_API_KEY` |
| 收信 live | `IMAP_USER`、`IMAP_PASS`；可选 `IMAP_HOST`（默认 `imap.qq.com`）、`IMAP_PORT`、`MAIL_FOLDER`、`MAIL_BACKEND=live`（默认 `mock`） |
| 入职 HCM | `HCM_API_URL` 与 `HCM_API_BASE` 等价，默认 `http://127.0.0.1:8000` |
| 转写 | `FUNASR_VENV` 或脚本 `--venv`；缺环境退出码 3 |

模板：[`env.sh.example`](../.openclaw-hr/env.sh.example)。**不要提交 `env.sh`。**

## 4. 硬规则

- **两个 conda 不要混**：`openclaw-hr` 是 numpy 2；`funasr_me` 是 numpy&lt;2 + torch。FunASR 进通用环境会把月报/画像打挂。
- **不要在 Agent `exec` 里 pip / npm**。缺包是 PATH 指错 Python，或本机没跑上面的 `conda env update`。
- OpenClaw 与 Lobster 钉 **2026.5.12**。
- 本机 ASR 仍跳过补测；没装 `funasr_me` 时招聘其它链路仍应能跑。
